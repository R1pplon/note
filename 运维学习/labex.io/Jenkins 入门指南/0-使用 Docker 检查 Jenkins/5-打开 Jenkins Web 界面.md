# 打开 Jenkins Web 界面

在此步骤中，你将把所检查的 Docker 容器与 Jenkins Web 界面关联起来。

从桌面界面打开 Firefox 浏览器。浏览器会自动打开 Jenkins 地址：

```plaintext
http://localhost:8080
```

在此环境中无需登录。

你应该能看到 Jenkins 仪表板。

![Jenkins 仪表板](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-installing-jenkins-with-docker/zh/../assets/step5-jenkins-dashboard.png)

这证实了 `jenkins` Docker 容器正在通过端口 `8080` 提供 Jenkins Web UI 服务。
