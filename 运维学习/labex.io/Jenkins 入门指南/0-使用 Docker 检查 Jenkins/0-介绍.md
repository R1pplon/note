# 简介

在本实验中，你将学习如何在 LabEx 的 Jenkins 环境中检查运行于 Docker 容器内的 Jenkins。Jenkins 服务已经安装并启动，可通过 `http://localhost:8080` 访问，因此你可以专注于理解 Docker 部署模型，而无需等待繁琐的安装过程。

你将练习以下操作：

- 检查宿主机上的 Docker 是否可用。
- 识别正在运行的 Jenkins 容器和镜像。
- 检查 Jenkins 使用的发布端口。
- 定位容器内的 Jenkins 主目录数据。
- 读取容器日志并打开 Jenkins Web 界面。

这些是在基于 Docker 的开发和培训环境中操作 Jenkins 的实用技能。
