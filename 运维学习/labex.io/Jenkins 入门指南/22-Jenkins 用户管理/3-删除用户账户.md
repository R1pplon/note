# 删除用户账户

在最后一步中，我们将学习如何从 Jenkins 中移除用户账户。当账户不再需要或你需要清理用户列表时，此操作非常有用。这是维护 Jenkins 实例安全的一项重要技能。

1. 如果你不在该页面，请点击左上角的 Jenkins 徽标返回 Jenkins 控制面板。

2. 点击右上角的齿轮图标访问 Jenkins 管理面板，然后点击 Security（安全）部分下的 "Users"（用户）返回用户管理页面。

3. 在用户列表中，找到我们之前创建的 `labex` 用户。使用该行对应的删除按钮。

4. 点击垃圾桶图标。系统会弹出一个确认对话框。这是一种防止意外删除的安全措施。

5. 仔细阅读警告信息。它会告知你删除用户后的后果。

6. 如果确定要删除该用户，请点击 "Yes"（是）进行确认。

   ![删除 Jenkins 用户](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-jenkins-user-management/zh/../assets/step3-delete-user.png)

   警告：此操作不可逆。一旦用户被删除，除非从备份中恢复，否则无法撤销此操作。

确认后，`labex` 用户将被移除。由于本实验创建并删除了唯一的 Jenkins 用户，删除后 Jenkins 可能会将你重定向到 **Create First Admin User**（创建第一个管理员用户）页面。该重定向是预期的，并确认当前已没有任何常规用户账户。

需要注意的是，删除用户是永久性操作。虽然它移除了用户登录的能力，但并不会自动将该用户从现有的作业配置或其他引用了该用户名的设置中移除。在删除用户时请务必谨慎，并确保你了解这对你的 Jenkins 设置产生的影响。
