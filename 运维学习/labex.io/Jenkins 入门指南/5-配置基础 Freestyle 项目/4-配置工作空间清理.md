# 配置工作空间清理

在最后一个配置步骤中，你将添加一个构建后操作来清理工作空间。这是一种良好的实践，可以节省磁盘空间并确保每次构建都在干净的环境中开始，从而防止之前构建产生的文件造成干扰。

1. 进入 `sample-project` 的配置页面。
2. 向下滚动到 **Post-build Actions** 部分。
3. 点击 **Add post-build action** 下拉菜单，选择 **Delete workspace when build is done**（构建完成后删除工作空间）。

![增加构建后操作下拉菜单](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step4-post-build-actions.png)

4. 点击 **Save**。

![工作空间清理配置](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step4-workspace-cleanup.png)

现在，在 `sample-project` 的每次构建完成后，Jenkins 都会删除工作空间目录中的所有文件。请注意，归档的产物是单独存储的，不受工作空间清理的影响。这确保了你的构建产物在保持可用的同时，也为下一次运行保持了干净的构建环境。
