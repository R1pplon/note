# 添加构建步骤

在此步骤中，你将为 Freestyle 项目添加一个构建步骤。构建步骤是项目的核心，它定义了 Jenkins 将要执行的操作，例如编译代码、运行测试或执行 Shell 脚本。

首先，让我们导航到项目配置页面。

1. 从桌面界面打开 Firefox 浏览器。浏览器会自动打开 `http://localhost:8080`，因此无需手动输入 URL。无需登录。
2. 在 Jenkins 仪表板上，你将看到 `sample-project`。点击其名称进入项目页面。
3. 在左侧菜单中，点击 **Configure**（配置）。

![Jenkins 项目页面](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step1-project-page.png)

现在，你已进入项目的配置页面。让我们添加一个构建步骤。

5. 向下滚动到 **Build Steps**（构建步骤）部分。
6. 点击 **Add build step**（增加构建步骤）下拉按钮，选择 **Execute shell**（执行 shell）。

![构建步骤部分](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step1-build-steps.png)

7. 将出现一个文本框。在 **Command**（命令）框中输入以下命令：

```bash
echo "Building the project..."
date
echo "Build complete."
```

8. 点击页面底部的 **Save**（保存）按钮。

你现在已经配置好了一个构建步骤。让我们运行构建来看看它的实际效果。

9. 在项目页面，点击左侧菜单中的 **Build Now**（立即构建）。
10. **Build History**（构建历史）部分将出现一个新的构建。点击构建编号（例如 `#1`）。
11. 在该构建的左侧菜单中，点击 **Console Output**（控制台输出）。

你将看到你添加的 Shell 命令的输出，这确认了你的构建步骤已成功执行。

```plaintext
Started by user admin
Running as SYSTEM
Building in workspace /var/jenkins_home/workspace/sample-project
[sample-project] $ /bin/sh -xe /tmp/jenkins12345.sh
+ echo 'Building the project...'
Building the project...
+ date
Tue Jan 1 12:00:00 UTC 2024
+ echo 'Build complete.'
Build complete.
Finished: SUCCESS
```
