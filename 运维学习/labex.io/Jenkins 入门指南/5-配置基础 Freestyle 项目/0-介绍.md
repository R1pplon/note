# 简介

欢迎来到关于配置 Jenkins 基础 Freestyle 项目的实验。Freestyle 项目是 Jenkins 中一种高度灵活且易于使用的选项，适用于各种类型的项目。它允许你通过基于 Web 的图形界面来配置构建触发器、构建步骤和构建后操作。

在本实验中，你将学习如何：

- 为项目添加 Shell 命令构建步骤。
- 使用触发器安排自动构建。
- 归档构建产物以供后续使用。
- 配置构建后操作，例如清理工作空间。

Jenkins 实例已经运行，并且已经为你创建了一个名为 `sample-project` 的基础 Freestyle 项目。你可以通过打开桌面上的 Firefox 浏览器来访问 Jenkins Web 界面。浏览器会自动打开 `http://localhost:8080`，因此无需手动输入 URL。无需登录。
