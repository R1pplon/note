# 归档构建产物

在此步骤中，你将学习如何归档构建产物。产物是构建产生的输出文件，例如编译后的二进制文件或报告。归档它们可以使你在构建完成后下载这些文件。

首先，我们需要修改构建步骤以创建一个可以归档的文件。

1. 导航到 `sample-project` 的配置页面。
2. 向下滚动到 **Build Steps** 部分，找到你的 **Execute shell** 命令框。
3. 在脚本中添加一行新代码，创建一个名为 `build-info.txt` 的文件。`$BUILD_NUMBER` 是 Jenkins 提供的环境变量，其中包含当前的构建编号。

```bash
echo "Building the project..."
date
echo "Build complete."
echo "This artifact is from build #$BUILD_NUMBER" > build-info.txt
```

接下来，让我们配置一个构建后操作来归档此文件。

4. 向下滚动到 **Post-build Actions**（构建后操作）部分。
5. 点击 **Add post-build action**（增加构建后操作）下拉菜单，选择 **Archive the artifacts**（归档成品）。

![增加构建后操作下拉菜单](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step3-post-build-actions.png)

6. 在 **Files to archive**（用于归档的文件）字段中，输入要归档的文件名：`build-info.txt`。你也可以使用通配符（如 `**/*.jar`）来归档多个文件。
7. 点击 **Save**。

![归档成品配置](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step3-archive-artifacts.png)

现在，点击 **Build Now** 运行一次新构建。构建完成后：

8. 点击 **Build History** 中的最新构建编号。
9. 在构建的状态页面上，你将看到一个名为 **Build Artifacts**（构建成品）的部分，其中包含指向 `build-info.txt` 的链接。你可以点击它来查看或下载该文件。

![已完成的构建页面](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-configuring-basic-freestyle-projects/zh/../assets/step3-build-artifacts.png)
