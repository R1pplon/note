# 访问并探索 Jenkins 仪表板

在此步骤中，你将登录 Jenkins Web 界面并熟悉主仪表板。Jenkins 服务已为你运行在容器中。

首先，访问 Jenkins Web 界面。点击 LabEx 屏幕顶部的 **Desktop Interface** 选项卡。在虚拟桌面中，打开 **Firefox** 网络浏览器。浏览器将自动打开 `http://localhost:8080`，因此你无需手动输入 URL。无需登录。

![Jenkins 仪表板](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step1-jenkins-dashboard.png)

你将看到 Jenkins 主仪表板。花点时间观察其关键组件：

- **导航侧边栏（左侧）：** 这是你的主要导航菜单。你可以在这里找到重要的链接，例如 `New Item`（用于创建新任务）和 `Build History`（所有构建的全局视图）。
- **主要内容区域：** 该区域显示你创建的所有任务列表。最初，这里是空的。

既然你已经熟悉了仪表板，现在可以开始创建你的第一个项目了。
