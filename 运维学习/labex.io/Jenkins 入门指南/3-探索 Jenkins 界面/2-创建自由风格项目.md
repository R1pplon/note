# 创建自由风格项目

在此步骤中，你将使用「自由风格项目」（Freestyle project）类型创建你的第一个 Jenkins 任务。自由风格项目是一种高度灵活且易于使用的选项，非常适合初学者和各种自动化任务。

1. 在 Jenkins Web 界面中，点击左侧导航侧边栏中的 **New Item**。

2. 在下一页，你需要为项目命名并选择其类型。

   - 在 **Enter an item name** 字段中，输入 `My-First-Job`。
   - 从选项列表中选择 **Freestyle project**。
   - 点击底部的 **OK** 按钮。

![Jenkins 项目创建页面](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step2-new-item.png)

3. 现在你将进入项目的配置页面。在这里你可以定义任务的具体操作。在本实验中，我们将添加一个简单的构建步骤。向下滚动到 **Build Steps** 部分。

4. 点击 **Add build step** 下拉按钮并选择 **Execute shell**。这允许你在构建过程中运行 shell 命令。

5. 将出现一个命令框。在此框中，输入以下命令：

   ```bash
   echo "Hello from my first Jenkins job!"
   ```

![带有构建步骤的 Jenkins 项目配置页面](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step2-build-step.png)

6. 最后，滚动到页面底部并点击 **Save** 按钮。

保存后，Jenkins 会将你重定向到新创建的项目 `My-First-Job` 的主页。
