# 运行构建任务

在此步骤中，你将运行（或称「构建」）你刚刚创建的任务。运行任务意味着执行你为其配置的步骤。

你现在应该在 `My-First-Job` 的项目页面上。如果你离开了该页面，可以通过点击 Jenkins 主仪表板上的项目名称返回。

1. 在 `My-First-Job` 的项目页面上，查看左侧的导航侧边栏。你会看到一个名为 **Build Now** 的选项。

![Jenkins 项目页面 Build Now 按钮](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step3-project-page.png)

2. 点击 **Build Now** 开始构建过程。

点击后，将安排一个新的构建。你会在左下角的 **Build History** 部分看到它出现。构建将被分配一个编号，从 `#1` 开始。

![Jenkins 构建历史](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step3-build-history.png)

构建编号旁边会出现一个小状态图标。闪烁的绿色图标表示构建正在进行中。实心绿色圆圈表示构建成功。由于我们的任务非常简单，它会在一两秒内完成。

现在，你已经成功触发了你的第一次构建。
