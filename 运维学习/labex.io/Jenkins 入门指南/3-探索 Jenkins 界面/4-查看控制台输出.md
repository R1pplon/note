# 查看控制台输出

在此步骤中，你将学习如何检查构建结果。查看输出是任何自动化流程的关键部分，因为它能告诉你确切发生了什么以及是否成功。

1. 在 `My-First-Job` 项目页面上，查看左下角的 **Build History** 部分。你应该能看到你的第一次构建，标记为 `#1`，并带有表示成功的绿色圆圈。

2. 点击构建编号 `#1` 进入该特定构建的详细信息页面。

3. 在构建页面上，你将看到有关构建的各种详细信息，例如运行时间。此处对于调试最重要的链接是 **Console Output**。点击左侧边栏中的 **Console Output**。

![构建详细信息页面上的控制台输出链接](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step4-build-page.png)

4. 控制台输出页面显示了 Jenkins 在构建过程中执行的每个操作的详细日志。你将看到 Jenkins 启动了构建，执行了你的 shell 命令，然后将构建标记为完成。

输出应如下所示：

![Jenkins 控制台输出](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-exploring-the-jenkins-interface/zh/../assets/step4-console-output.png)

```plaintext
Started by user admin
Running as SYSTEM
Building in workspace /var/jenkins_home/workspace/My-First-Job
[My-First-Job] $ /bin/sh -xe /tmp/jenkins12345.sh
+ echo 'Hello from my first Jenkins job!'
Hello from my first Jenkins job!
Finished: SUCCESS
```

正如你所见，日志包含了我们配置的 `echo` 命令及其输出：`Hello from my first Jenkins job!`。最后的 `Finished: SUCCESS` 状态确认了任务在没有任何错误的情况下运行完成。
