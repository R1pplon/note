# 简介

在现代 CI/CD 流水线中，灵活性和自动化是关键。将数值硬编码到构建任务中会使其变得僵化且难以管理。Jenkins 允许你通过参数化构建并在构建过程中执行脚本来克服这一问题。

在本实验中，你将学习如何创建一个灵活的 Jenkins 任务。首先，你将添加参数以允许在构建时进行用户输入。接着，你将学习如何将 Shell 脚本作为构建步骤执行，将参数传递给这些脚本，并配置能够根据构建成功或失败做出响应的构建后操作。这些是创建健壮且动态的 Jenkins 自动化工作流的基本技能。

你的环境中已经运行了一个 Jenkins 实例。你可以通过打开桌面上的 Firefox 浏览器访问 Jenkins Web 界面。浏览器会自动打开 `http://localhost:8080`，因此无需手动输入 URL。无需登录。
