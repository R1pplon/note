# 审计已安装的插件

## 当前状况

Jenkins 镜像中已经包含了一些常用插件。在进行任何更改之前，你需要记录证据，证明 Git 插件已安装并可用。

## 范围

- Jenkins 运行在名为 `jenkins` 的 Docker 容器中。
- 插件文件位于容器内的 `/var/jenkins_home/plugins` 目录下。
- 将你的审计结果写入 `/home/labex/project/plugin-audit.txt`。

## 目标

创建一个插件审计报告，证明 Git 插件已安装在此 Jenkins 实例中。

## 验收标准

- 报告文件存在于 `/home/labex/project/plugin-audit.txt`。
- 报告中列出了 Git 插件文件。
- 报告中包含了来自容器内部的 Jenkins 插件目录证据。

## 提示

<details>
<summary>需要一个起点吗？</summary>

使用 `docker exec jenkins` 配合 `ls` 或 `find` 命令来查看 `/var/jenkins_home/plugins`。
</details>
