# 简介

欢迎来到 Jenkins 流水线基础实验。Jenkins 流水线（Pipeline）是一项强大的功能，允许你将整个构建、测试和部署过程定义为代码。这种定义存储在一个名为 `Jenkinsfile` 的文本文件中，通常与应用程序的源代码一起进行版本控制。这种实践被称为「流水线即代码」（Pipeline-as-Code）。

在本实验中，你将重点学习声明式流水线（Declarative Pipeline）语法，它提供了一种结构化且用户友好的方式来创建流水线。通过本实验，你将能够：

- 在 Jenkins Web 界面中创建一个新的流水线项目。
- 使用声明式语法编写基础的 `Jenkinsfile`。
- 配置项目以使用来自本地 Git 仓库的 `Jenkinsfile`。
- 运行流水线并检查其输出。
- 将流水线组织为多个阶段（Stage）。
- 使用环境变量来管理配置。

一个 Jenkins 实例已经在容器中为你运行。让我们开始吧。
