# 理解流水线中的多个阶段

现实世界中的流水线由多个阶段组成，例如构建、测试和部署应用程序。本地仓库中的 `Jenkinsfile` 已经包含了这些不同的阶段，展示了这个重要的概念。

让我们检查一下流水线是如何通过多个阶段构建的：

```groovy
stages {
    stage('Build') {
        steps {
            echo 'Building the application...'
            sh 'echo "Compiling source code..."'
        }
    }
    stage('Test') {
        steps {
            echo 'Testing the application...'
            sh 'echo "Running unit tests..."'
        }
    }
    stage('Deploy') {
        steps {
            echo "Deploying the application to ${env.DEPLOY_TARGET}..."
            sh 'echo "Application deployed successfully!"'
        }
    }
}
```

1. 回到 `my-first-pipeline` 项目的 Jenkins UI，如果尚未运行，请点击 **Build Now** 再次运行流水线。

2. 观察项目仪表板上的 **Stage View**。你将看到代表 "Build"、"Test" 和 "Deploy" 阶段的三列。Jenkins 会在构建通过每个阶段时可视化其进度。

   ![显示 Build Test Deploy 阶段的 Jenkins 阶段视图](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-introduction-to-jenkins-pipelines/zh/../assets/step4-stage-view.png)

3. 点击阶段视图中的任何阶段，查看该特定阶段的详细日志。

4. 注意每个阶段是如何按顺序执行的——Jenkins 会等待一个阶段成功完成后，才会进入下一个阶段。

通过使用阶段来组织流水线，你可以创建一个清晰且易于维护的工作流，便于监控。每个阶段代表 CI/CD 过程中的一个逻辑环节，这使得识别问题发生的位置以及可视化构建进度变得非常容易。
