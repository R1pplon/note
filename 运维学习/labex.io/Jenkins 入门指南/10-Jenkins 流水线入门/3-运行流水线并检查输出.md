# 运行流水线并检查输出

项目配置完成后，是时候运行流水线并查看其实际效果了。

1. 在 `my-first-pipeline` 项目页面上，点击左侧菜单中的 **Build Now**（立即构建）。
2. 一个新的构建将被调度，并出现在左侧的 **Build History**（构建历史）面板中。在历史记录下方，**Stage View**（阶段视图）将显示 "Build" 阶段正在运行，并在完成后变为绿色。

   ![流水线项目构建历史](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-introduction-to-jenkins-pipelines/zh/../assets/step3-pipeline-project.png)

3. 要查看详细输出，请点击构建历史中的构建编号（例如 **#1**）。
4. 在构建的摘要页面上，点击左侧菜单中的 **Console Output**（控制台输出）。

   ![显示流水线成功执行的控制台输出](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-introduction-to-jenkins-pipelines/zh/../assets/step3-console-output.png)

5. 滚动查看日志。你将找到来自流水线步骤的消息，确认流水线已成功执行。

```plaintext
...
[Pipeline] { (Build)
[Pipeline] echo
Building the application...
[Pipeline] sh
+ echo Compiling source code...
Compiling source code...
[Pipeline] } // stage
[Pipeline] { (Test)
[Pipeline] echo
Testing the application...
[Pipeline] sh
+ echo Running unit tests...
Running unit tests...
[Pipeline] } // stage
[Pipeline] { (Deploy)
[Pipeline] echo
Deploying the application to staging...
[Pipeline] sh
+ echo Application deployed successfully!
Application deployed successfully!
[Pipeline] } // stage
...
Finished: SUCCESS
```

你已经成功运行了第一个流水线并验证了其输出。请注意流水线是如何自动执行仓库 `Jenkinsfile` 中定义的全部三个阶段（Build、Test、Deploy）的。
