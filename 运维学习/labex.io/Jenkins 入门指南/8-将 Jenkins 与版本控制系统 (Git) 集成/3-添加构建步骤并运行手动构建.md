# 添加构建步骤并运行手动构建

既然 Jenkins 已经知道从哪里获取代码，你需要告诉它如何处理这些代码。你将添加一个包含 shell 命令的构建步骤，然后手动运行构建来测试它。

1. 在 `git-integration-project` 的项目页面上，点击左侧边栏中的 **Configure**（配置）。
2. 向下滚动到 **Build Steps**（构建步骤）部分。
3. 点击 **Add build step**（增加构建步骤）下拉菜单，选择 **Execute shell**（执行 shell）。
4. 在 **Command**（命令）文本区域中，输入以下构建命令：

```bash
echo "Building from the Git repository"
./build.sh
```

当作业运行时，Jenkins 会首先将 Git 仓库克隆到其工作区，然后从该工作区内执行这些命令。`build.sh` 脚本来自仓库，因此运行成功证明 Jenkins 在执行 shell 步骤之前已经检出了代码。

5. 点击 **Save**（保存）。
6. 你现在回到了项目页面。点击左侧边栏中的 **Build Now**（立即构建）以启动构建。

一个新的构建将出现在 **Build History**（构建历史）面板中。等待其完成（状态图标将变为蓝色，表示成功）。

7. 点击构建编号（例如 `#1`）。
8. 从构建菜单中点击 **Console Output**（控制台输出）。

![成功的 Git 构建](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-integrating-jenkins-with-source-control-git/zh/../assets/step3-successful-build.png)
