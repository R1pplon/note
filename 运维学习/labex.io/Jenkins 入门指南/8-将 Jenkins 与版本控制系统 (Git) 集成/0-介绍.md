# 简介

欢迎来到本次关于将 Jenkins 与 Git 集成的实验。版本控制管理（SCM）是现代软件开发的基石。将 Jenkins 等持续集成（CI）服务器与 Git 等 SCM 系统集成，是实现构建和测试流程自动化的基础步骤。

在本次实验中，你将学习如何：

- 验证 Jenkins Git 插件是否可用。
- 创建一个链接到本地 Git 仓库的自由风格项目。
- 添加一个构建步骤，以执行来自仓库的脚本。
- 手动运行构建以测试配置。
- 配置 SCM 轮询，以便在新提交时自动触发构建。

本次实验已经准备好了一个 Jenkins 实例和一个小型本地 Git 仓库。你可以通过打开桌面上的 Firefox 浏览器来访问 Jenkins Web 界面。浏览器会自动打开 `http://localhost:8080`，因此无需手动输入 URL。无需登录。
