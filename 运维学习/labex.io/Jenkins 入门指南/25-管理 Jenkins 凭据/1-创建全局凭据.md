# 创建全局凭据

## 当前状况

Jenkins 正在运行，但尚未为作业准备任何实验凭据。

## 范围

- 创建一个全局用户名/密码凭据。
- 凭据 ID 必须为 `labex-creds`。
- 用户名必须为 `labex-user`。

## 你的目标

创建一个 Jenkins 凭据，以便作业可以通过稳定的 ID `labex-creds` 进行引用。

## 验收标准

- Jenkins 中存储了一个 ID 为 `labex-creds` 的凭据。
- 该凭据记录包含用户名 `labex-user`。

## 提示

<details>
<summary>需要入门指导？</summary>

使用 Jenkins UI 中的“凭据”（Credentials）菜单，或者使用 `scriptText` 调用 Jenkins 凭据 API。
</details>
