# 删除用户账户

## 当前情况

用户管理审计完成后，临时账户 `labex` 已不再需要。

## 范围

- 仅删除 ID 为 `labex` 的 Jenkins 用户。
- 保持 Jenkins 本身运行。

## 目标

从 Jenkins 中删除 `labex` 用户账户。

## 验收标准

- Jenkins 不再存储 ID 为 `labex` 的用户记录。
- Jenkins 依然可以通过 `http://localhost:8080/login` 访问。

## 提示

<details>
<summary>需要入门指导？</summary>

Jenkins 的 `hudson.model.User.getById(...).delete()` API 可以删除本地用户。
</details>
