# 创建新用户

## 当前情况

Jenkins 控制器已就绪并使用内部用户数据库。后续的自动化练习需要一个服务账户。

## 范围

- Jenkins 可通过 `http://localhost:8080` 访问。
- 账户 ID 必须为 `labex`。
- 账户全名必须为 `Lab User`。

## 目标

创建一个名为 `labex` 的 Jenkins 用户账户，设置可用密码，并将全名设为 `Lab User`。

## 验收标准

- Jenkins 存储了 ID 为 `labex` 的用户记录。
- 存储的用户配置中包含 `Lab User`。

## 提示

<details>
<summary>需要入门指导？</summary>

使用带有 crumb 的 Jenkins `scriptText`，或者在 Jenkins UI 的安全域（security realm）下创建用户。
</details>
