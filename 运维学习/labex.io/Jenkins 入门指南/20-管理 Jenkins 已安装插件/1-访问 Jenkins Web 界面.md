# 访问 Jenkins Web 界面

在管理插件之前，你需要访问 Jenkins Web 界面。Jenkins 实例已经为你运行。

1. 从桌面界面打开 Firefox 浏览器。浏览器将自动打开 `http://localhost:8080`，因此你无需手动输入 URL。无需登录。
