# 卸载插件

在最后一步中，你将学习 Jenkins 如何标记插件以进行移除。移除未使用的插件有助于保持 Jenkins 实例的整洁、安全和高性能。你将卸载 **Ant Plugin**，它在实验镜像中可用，且之前的步骤不需要它。

1. 点击 Jenkins 仪表板右上角的齿轮图标以访问 Jenkins 管理面板，然后点击 **Plugins**（插件）以导航到插件管理器。
2. 点击 **Installed plugins**（已安装插件）选项卡。此选项卡显示当前安装在 Jenkins 实例上的所有插件。
3. 在搜索框中输入 `ant` 以快速找到该插件。
4. 找到 **Ant Plugin**，然后点击插件条目右侧的 **Uninstall**（卸载）按钮（看起来像一个 X 图标）。
5. Jenkins 会要求确认。阅读消息，然后点击 **Yes**（是）。
6. 确认后，Jenkins 会为该插件显示 **Uninstallation pending**（等待卸载）。

   ![Ant 插件等待卸载](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-managing-plugins-in-jenkins/zh/../assets/step4-uninstallation-pending.png)

这会将插件二进制文件标记为移除。Jenkins 会保留插件配置文件，以便管理员在需要时可以稍后恢复设置。
