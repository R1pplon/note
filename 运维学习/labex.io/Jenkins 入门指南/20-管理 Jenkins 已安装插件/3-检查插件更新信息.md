# 检查插件更新信息

保持插件更新对于安全性、稳定性和获取新功能至关重要。在此步骤中，你将了解 Jenkins 在不应用任何更改的情况下显示更新信息的位置。

1. 点击 Jenkins 仪表板右上角的齿轮图标以访问 Jenkins 管理面板，然后点击 **Plugins**（插件）以导航回插件管理器。
2. 点击 **Updates**（更新）选项卡。此选项卡列出了在更新中心有新版本可用的已安装插件。

   ![Jenkins 插件更新选项卡](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-managing-plugins-in-jenkins/zh/../assets/step3-plugin-updates.png)

3. 观察插件列表。根据当前的更新中心元数据，本实验中的 Jenkins 实例可能会也可能不会有待处理的更新。
4. 点击左侧边栏中的 **Advanced settings**（高级设置）。
5. 查看更新站点 URL。Jenkins 使用此更新站点来检查插件元数据。

在本实验中，请勿安装或更新插件。目标是了解更新信息的显示位置以及 Jenkins 存储更新中心配置的位置。
