# 浏览已安装的插件

在此步骤中，你将学习如何使用插件管理器搜索已安装的插件。这是审计 Jenkins 控制器时最安全的首要操作，因为它不会更改系统。

首先，确保你已经访问了 Jenkins 界面。

1. 在 Jenkins 主仪表板上，点击右上角的齿轮图标以访问设置面板。
2. 在设置面板中，点击 **Plugins**（插件）。

![Jenkins 管理 Jenkins 页面插件链接](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-managing-plugins-in-jenkins/zh/../assets/step2-manage-jenkins-plugins.png)

3. 你将被带到插件管理器。点击 **Installed plugins**（已安装插件）选项卡。
4. 在搜索框中输入 `git` 以过滤列表。
5. 确认 **Git plugin** 出现在结果中。注意插件的版本、健康评分、启用状态以及卸载操作。

![已安装的 Git 插件](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/jenkins/lab-managing-plugins-in-jenkins/zh/../assets/step2-installed-git-plugin.png)

现在你已经确认 Jenkins 可以列出已安装的插件并显示其当前状态。
