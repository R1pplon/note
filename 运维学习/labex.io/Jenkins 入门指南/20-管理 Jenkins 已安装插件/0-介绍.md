# 简介

Jenkins 的强大之处在于其可扩展性，而这得益于其庞大的插件生态系统。插件可以添加新功能、与其他工具集成并增强用户界面。对于任何 Jenkins 管理员来说，有效管理这些插件都是一项关键技能。

在本实验中，你将通过 Web 界面获得 Jenkins 管理和插件生命周期管理的实践经验。为了确保练习的稳定性，你将使用实验镜像中已有的插件，而不是从互联网下载新插件。你将学习如何：

- 打开 Jenkins 插件管理器。
- 搜索已安装的插件并查看插件元数据。
- 检查更新中心和高级插件设置。
- 标记已安装的插件以进行移除。

一个 Jenkins 实例已经为你运行并准备好进行插件管理。
