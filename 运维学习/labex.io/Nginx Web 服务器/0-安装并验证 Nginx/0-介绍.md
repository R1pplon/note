# 简介

**Nginx**（发音为「engine-x」）是世界上最流行的 Web 服务器之一。Web 服务器负责接收来自客户端的 HTTP 请求，并返回网页内容，例如 HTML 页面、图片或 API 响应。

Web 服务器本身并不是网站内容，它是一种监听网络请求的服务，负责决定如何处理这些请求以及返回什么样的响应。

Nginx 以其事件驱动的架构而闻名，这种架构使其能够高效地处理大量并发连接。这也是它在高流量网站和反向代理配置中广受欢迎的原因。

在本实验中，你将迈出 Web 托管的第一步。你将学习如何：

1. 在 Linux 系统上安装 Nginx 软件。
2. 管理 Nginx 后台服务。
3. 验证服务器是否正在监听连接。
4. 测试服务器以查看其运行效果。

我们将指导你完成每一条命令，即使你是 Linux 新手，也能轻松完成本实验。
