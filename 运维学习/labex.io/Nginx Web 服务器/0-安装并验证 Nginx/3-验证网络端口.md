# 验证网络端口

Web 服务器通常监听 **80 端口**。你可以将端口想象成建筑物中的特定门。计算机是建筑物，而 80 端口是标有「Web 请求」的门。Nginx 需要保持这扇门打开，以便让用户进入。

80 端口是普通 HTTP 流量的标准默认端口。当浏览器或 `curl` 在没有 HTTPS 的情况下发出简单的 Web 请求时，除非另有说明，否则这就是默认的目标端口。

我们将使用名为 `ss` 的网络工具来检查当前哪些端口处于打开（监听）状态。

运行以下命令：

```bash
sudo ss -tuln
```

**参数含义：**

* `-t`：显示 **TCP** 连接（Web 使用的协议）。
* `-u`：显示 **UDP** 连接。
* `-l`：显示 **Listening**（监听）套接字（即打开的端口）。
* `-n`：显示 **Numbers**（数字，例如「80」）而不是服务名称（例如「http」）。

为了更方便地在结果中找到 Nginx，我们可以使用 `grep` 过滤输出：

```bash
sudo ss -tuln | grep :80
```

你应该会看到一行包含 `LISTEN` 和 `:80` 的输出。这确认了 Nginx 已成功在 80 端口上监听，并准备好接受连接。
