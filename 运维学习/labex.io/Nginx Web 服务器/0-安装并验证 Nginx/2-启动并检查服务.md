# 启动并检查服务

安装软件只是将文件放入磁盘，但 Nginx 被设计为以**服务**（或守护进程）的形式运行。这意味着它会在后台静默运行，等待 Web 请求。

区分已安装的软件和活跃的服务非常重要。软件包可以存在于机器上，而服务器进程可能处于停止状态，不提供任何服务。

首先，让我们检查 Nginx 服务的状态，看看它是否正在运行：

```bash
sudo service nginx status
```

在某些环境中，服务会在安装后自动启动。而在另一些环境中，它可能处于停止状态。

如果状态不是「running」（或者你只是想确保它已启动），请显式启动该服务：

```bash
sudo service nginx start
```

这能确保你的「数字服务员」已就绪，随时准备处理请求。
