# 触发 404 错误

现在是测试成果的时候了。我们将故意尝试访问一个不存在的页面，看看服务器如何响应。

首先，通过检查主页的响应头来确认网站运行正常：

```bash
curl -I http://localhost/
```

你应该会看到 `HTTP/1.1 200 OK`。`-I` 标志告诉 curl 只获取响应头（状态码），而不获取页面内容。

现在，尝试访问一个肯定不存在的页面，例如 `/missing_page`：

```bash
curl -I http://localhost/missing_page
```

你应该会看到 `HTTP/1.1 404 Not Found`。

这确认了服务器保持了正确的 HTTP 语义。除非你刻意想要不同的行为，否则自定义错误页面仍应报告正确的错误状态。

这证实了 Nginx 正确识别出页面缺失。在下一步中，我们将检查它在发送错误代码的同时是否发送了*正确的内容*。
