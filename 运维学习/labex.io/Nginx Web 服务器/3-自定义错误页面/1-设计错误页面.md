# 设计错误页面

在这一步中，你将创建 Nginx 在发生错误时显示的 HTML 文件。Ubuntu 上的 Nginx 通常从 `/var/www/html` 目录提供文件，因此我们将把新文件放在那里。

自定义错误页面是分离响应状态与响应内容的绝佳示例。HTTP 状态码可以保持为 404，而向用户展示的页面主体则可以完全自定义。

首先，进入 Web 根目录：

```bash
cd /var/www/html
```

现在，使用 `nano` 文本编辑器创建一个名为 `custom_404.html` 的新文件：

```bash
sudo nano custom_404.html
```

将以下 HTML 代码复制并粘贴到编辑器中。这个简单的页面会向用户显示一条友好且经过样式美化的消息：

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Page Not Found</title>
    <style>
      body {
        font-family: Arial, sans-serif;
        text-align: center;
        padding: 50px;
      }
      h1 {
        color: #e74c3c;
      }
    </style>
  </head>
  <body>
    <h1>Oops! Page Not Found</h1>
    <p>We could not find the page you were looking for.</p>
    <p>Please check the URL or go back to the homepage.</p>
  </body>
</html>
```

在 `nano` 中保存文件：

1. 按 `Ctrl + O`，然后按 `Enter` 确认。
2. 按 `Ctrl + X` 退出。

验证文件是否创建成功：

```bash
ls -l custom_404.html
```
