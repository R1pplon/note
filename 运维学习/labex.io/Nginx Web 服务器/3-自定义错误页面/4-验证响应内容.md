# 验证响应内容

最后，让我们验证用户看到的是你漂亮的 HTML 页面，而不是默认的简陋页面。

再次运行 `curl` 命令，但这次**不要**使用 `-I` 标志，这样我们就可以看到实际的 HTML 代码：

```bash
curl http://localhost/this-page-does-not-exist
```

查看输出。你应该能看到来自 `custom_404.html` 文件的 HTML 代码：

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page Not Found</title>
...
    <h1>Oops! Page Not Found</h1>
...
</html>
```

如果你看到了「Oops! Page Not Found」，恭喜你！你已经成功用自己的自定义设计替换了默认的错误消息。
