# 保护管理仪表板

我们有一个敏感区域位于 `/admin`（默认映射到 `/var/www/html/admin`）。我们必须确保只有授权人员才能访问它。

## 任务

1. 在 `/etc/nginx/` 中为名为 `admin` 的用户创建一个密码文件 `.htpasswd`。
2. 更新 Nginx 配置以保护 `/admin` 路径。
3. 使用 **基本身份验证** (`auth_basic`)。
4. 重新加载 Nginx。
5. 验证 `curl http://localhost/admin` 是否返回 **401 Unauthorized** 错误。

## 要求

- 密码文件：`/etc/nginx/.htpasswd`。
- 用户名：`admin`。
- 必须保护 `/admin` 路径。

## 示例

完成任务后，你可以运行以下命令来验证管理区域是否已受到保护：

```bash
curl http://localhost/admin
```

你应该看到以下输出：

```plain
401 Unauthorized
```

## 提示

<details>
<summary>提示：创建密码文件</summary>

使用 `htpasswd -c` 创建文件。

```bash
sudo htpasswd -c /etc/nginx/.htpasswd admin
```

</details>

<details>
<summary>提示：身份验证配置</summary>

```nginx
location /admin {
    auth_basic "Restricted";
    auth_basic_user_file /etc/nginx/.htpasswd;
}
```

</details>
