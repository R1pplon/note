# 配置静态资源服务

营销团队已将他们的文件放置在 `/var/www/static` 中。我们需要在用户访问 `/static` URL 时提供这些文件。

你在虚拟主机实验中学习过 `root` 指令。当你在块中定义 `root` 时，Nginx 会将 URI 附加到该根路径以查找文件。

例如，如果 `root` 是 `/var/www`，而请求是 `/static/index.html`，Nginx 会查找 `/var/www` + `/static/index.html`。

## 任务

1. 在同一个配置文件中，为 `/static` 添加一个新的 `location` 块。
2. 在此块内，将 `root` 设置为 `/var/www`。
3. 重新加载 Nginx。
4. 验证 `curl http://localhost/static/index.html` 是否成功返回内容。

## 要求

- 创建一个 `location /static { ... }` 块。
- 使用指向 `/var/www` 的 `root` 指令。
- 这会将对 `/static` 的请求映射到 `/var/www/static`。

## 示例

完成任务后，你可以运行以下命令来验证静态文件是否已成功提供：

```bash
curl http://localhost/static/index.html
```

你应该看到以下输出：

```plain
Static Content Served Successfully
```

## 提示

<details>
<summary>提示：Root 指令</summary>

```nginx
location /foldername {
    root /parent/directory;
}
```

如果你为 `location /static` 设置了 `root /var/www;`，那么对 `/static/file.html` 的请求将会在 `/var/www/static/file.html` 中查找。

</details>
