# 实现自定义 404 页面

通用的「404 Not Found」错误对用户体验很不友好。我们希望显示一个带有品牌特色的错误页面。

## 任务

1. 在 `/var/www/html/` 中创建一个名为 `custom_404.html` 的自定义 HTML 文件。
    - 你可以在其中放入任何内容，例如：`<h1>Oops! Page Not Found</h1>`。
2. 配置 Nginx 以便在发生 **404** 错误时使用此文件。
    - 使用 `error_page` 指令。
    - 为该文件创建一个 `location` 块并将其标记为 `internal`。
3. 重新加载 Nginx。
4. 通过尝试访问不存在的页面（例如 `curl http://localhost/nothing`）进行测试。

## 要求

- 文件路径：`/var/www/html/custom_404.html`。
- 指令：在 server 块内添加 `error_page 404 /custom_404.html;`。
- Location：使用 `location = /custom_404.html { ... }` 并包含 `internal;`。

## 示例

完成任务后，你可以运行以下命令来验证自定义错误页面是否已生效：

```bash
curl http://localhost/nothing
```

你应该看到以下输出：

```plain
Oops! Page Not Found
```
