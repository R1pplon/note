# 扩展应用程序

使用 Docker Swarm 的一个好处是能够水平扩展你的应用程序。在这一步中，你将学习如何将示例 Node.js 应用程序扩展到以处理更多流量。

## 目标

将示例 Node.js 应用程序扩展到五个副本（replicas）。
