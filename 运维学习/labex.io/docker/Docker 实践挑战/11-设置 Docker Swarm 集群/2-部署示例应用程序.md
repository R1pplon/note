# 部署示例应用程序

现在你已经设置好了 Docker Swarm 集群，可以部署你的第一个应用程序了。在这一步中，你将学习如何将一个示例应用程序部署到 Docker Swarm 上。

## 目标

将一个示例 Node.js 应用程序部署到 Docker Swarm。

## 结果示例

1. 下载 `docker-compose`。

![Downloading docker compose file](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-docker-swarm/zh/../assets/challenge-docker-swarm-basics-tutorial-2-2.png)

2. 创建一个 `docker-compose.yml` 文件，内容如下：

```yml
version: "3.8"
services:
  nginx:
    image: nginx
    ports:
      - "80:80"
```

3. 使用 `docker stack` 部署应用程序，栈（stack）命名为 `mystack`。

![Deploying application with docker stack](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-docker-swarm/zh/../assets/challenge-docker-swarm-basics-tutorial-2-4.png)

4. 验证应用程序是否已启动并正在运行。

![Application running verification](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-docker-swarm/zh/../assets/challenge-docker-swarm-basics-tutorial-2-5.png)
