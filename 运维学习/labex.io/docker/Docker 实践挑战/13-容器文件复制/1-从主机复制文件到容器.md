# 从主机复制文件到容器

`docker cp` 命令可用于将文件从本地机器复制到正在运行的 Docker 容器中。当你需要向容器中添加文件或更新容器内的现有文件时，这非常有用。

## 目标

在这一步中，你的目标是将名为 `file.txt` 的文件从本地机器复制到名为 `my_container` 的正在运行的 Docker 容器中，该容器基于 `ubuntu:18.04` 镜像。

## 结果示例

以下是你完成此步骤时应能实现的效果示例：

1. 使用 `docker run` 命令启动一个基于 `ubuntu:18.04` 镜像的名为 `my_container` 的容器。

```
labex:~/ $ docker ps -a | grep my_container
1ae16bca3820   ubuntu:18.04                          "/bin/bash"              20 seconds ago   Up 18 seconds                                                                                                                                                      my_container
```

2. 在本地计算机的 `~/project` 目录下创建一个名为 `file.txt` 的文件，其中包含一些自定义内容。

```
labex:project/ $ pwd
/home/labex/project
labex:project/ $ ll | grep  file.txt
-rw-r--r-- 1 labex labex 0 Jan 22 09:44 file.txt
```

3. 将 `file.txt` 文件复制到 `my_container` 容器的 `tmp` 目录中。

```
labex:project/ $ docker exec my_container ls /tmp/
file.txt
```

## 要求

- 本地机器上安装了 Docker。

- 一个正在运行的 Docker 容器。
