# 从主机复制目录到容器

`docker cp` 命令也可用于将目录从本地机器复制到正在运行的 Docker 容器中。当你需要向容器中添加目录或更新容器内的现有目录时，这非常有用。

## 目标

在这一步中，你的目标是将名为 `labexx` 的目录从本地机器复制到名为 `my_container3` 的正在运行的 Docker 容器中。

## 结果示例

以下是你完成此步骤时应能实现的效果示例：

1. 启动一个基于 `ubuntu:18.04` 镜像的名为 `my_container3` 的容器。

```
labex:project/ $ docker ps | grep my_container3
4673a8381336   ubuntu:18.04   "sleep 3600"   17 seconds ago   Up 16 seconds             my_container3
```

2. 在本地机器的 `/tmp` 目录下创建一个名为 `labexx` 的目录，并填充一些文件。

```
labex:project/ $ ls /tmp/labexx
file1  file2
```

3. 将本地机器上的 `labexx` 目录复制到正在运行的容器的同一目录下。

```
labex:project/ $ docker exec my_container3 ls /tmp/labexx
file1
file2
```

## 要求

- 本地机器上安装了 Docker。

- 一个正在运行的 Docker 容器。

- 本地机器上有一个名为 `labexx` 的目录。
