# 从容器复制目录到主机

`docker cp` 命令也可用于在本地机器和正在运行的 Docker 容器之间复制目录。当你需要将多个文件或整个目录传输到容器内或从容器中取出时，这非常有用。

## 目标

在这一步中，你的目标是将名为 `labex` 的目录从名为 `my_container2` 的正在运行的 Docker 容器复制到你的本地机器上。

## 结果示例

以下是你完成此步骤时应能实现的效果示例：

1. 启动一个基于 `ubuntu:18.04` 镜像的名为 `my_container2` 的容器。

```
labex:project/ $ docker ps | grep my_container2
b2bcfe7c7b96   ubuntu:18.04   "/bin/bash"   25 seconds ago   Up 25 seconds             my_container2
```

2. 在容器内，在 `/tmp` 目录下创建一个名为 `labex` 的目录，并在其中放置一些文件。

```
labex:project/ $ docker exec my_container2 ls /tmp/labex
file1
file2
```

3. 将容器中的 `labex` 目录复制到本地机器上的同一目录下。

```
labex:project/ $ ll /tmp/labex
total 0
-rw-r--r-- 1 labex labex 0 Jan 22 09:54 file1
-rw-r--r-- 1 labex labex 0 Jan 22 09:54 file2
```

## 要求

- 本地机器上安装了 Docker。

- 一个包含名为 `labex` 目录的正在运行的 Docker 容器。
