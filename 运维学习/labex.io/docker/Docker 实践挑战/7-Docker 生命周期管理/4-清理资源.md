# 清理资源

在这一步骤中，我们将清理在之前步骤中创建的资源。

## 目标

你的目标是停止并删除所有正在运行的容器。然后删除 `my-web-server` 镜像。

## 结果示例

以下是你在本步骤结束时应能完成的效果示例：

1. 停止并删除所有正在运行的容器。

```
labex:hello-docker/ $ docker ps -a
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
labex:hello-docker/ $
```

2. 删除标签为 `my-web-server` 的 Docker 镜像。

```
labex:hello-docker/ $ docker images | grep my
labex:hello-docker/ $
```

## 要求

- 你的机器上必须已安装 Docker。
