# 基础容器网络

在这一步中，你将学习如何在单主机上运行几个 Docker 容器，并使用一个网络将它们连接起来。

## 目标

完成此步骤后，你应该能够运行两个容器并将它们连接到一个网络。

## 结果示例

1. 创建一个名为 `my_network` 的新 Docker 网络。

![Creating Docker network my_network](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-single-host-container-interconnection/zh/../assets/challenge-single-host-container-interconnection-1-1.png)

2. 使用 `alpine` 镜像启动两个名为 `container1` 和 `container2` 的容器，并将它们连接到 `my_network` Docker 网络。

![Two containers connected to network](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-single-host-container-interconnection/zh/../assets/challenge-single-host-container-interconnection-1-2.png)

3. 检查两个容器是否都已连接到该网络。

![containers connected to network](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-single-host-container-interconnection/zh/../assets/challenge-single-host-container-interconnection-1-3.png)
