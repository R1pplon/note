# 容器名称和链接

在这一步中，你将学习如何使用容器名称和链接在单主机上连接容器。

## 目标

完成此步骤后，你应该能够使用容器名称和链接来连接两个或多个容器。

## 结果示例

1. 使用 `alpine` 镜像启动第一个名为 `container3` 的容器。

![Starting container3 with alpine](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-single-host-container-interconnection/zh/../assets/challenge-single-host-container-interconnection-2-1.png)

2. 使用 `alpine` 镜像启动第二个名为 `container4` 的容器，并将其链接到第一个容器。

![linking containers on host](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-single-host-container-interconnection/zh/../assets/challenge-single-host-container-interconnection-2-2.png)

3. 检查两个容器是否已连接。
