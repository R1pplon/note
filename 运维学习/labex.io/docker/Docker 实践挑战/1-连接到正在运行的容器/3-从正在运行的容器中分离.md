# 从正在运行的容器中分离

在这一步中，你将学习如何在不停止容器的情况下从正在运行的容器中分离。

## 目标

从 `my-nginx` 容器中分离。

## 结果示例

以下是你在此步骤结束时应该能够实现的目标：

从 `my-nginx` 容器中分离。

你可以通过运行 `docker ps` 命令来验证你是否已不再连接到该容器。

```
labex:~/ $ docker ps
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS     NAMES
e370ef667e69   nginx     "/docker-entrypoint.…"   9 minutes ago   Up 3 minutes   80/tcp    my-nginx
```

## 要求

- 你的机器上必须安装 Docker。
- 容器必须处于运行状态。
