# 连接到正在运行的容器

在这一步中，你将学习如何使用 `docker attach` 命令连接到正在运行的容器。

## 目标

连接到 `my-nginx` 容器。

## 结果示例

以下是你在此步骤结束时应该能够实现的目标：

1. 打开终端或命令行提示符。

2. 运行 `docker attach` 命令连接到 `my-nginx` 容器。

```bash
docker attach my-nginx
```

命令连接后，你的终端将保持与容器的连接，并且不会返回到 shell 提示符。

`nginx` 可能不会立即打印任何新的日志行。这是正常的。如果终端已连接并处于等待状态，则说明命令执行成功。

## 要求

- 你的机器上必须安装 Docker。

- 容器必须处于运行状态。
