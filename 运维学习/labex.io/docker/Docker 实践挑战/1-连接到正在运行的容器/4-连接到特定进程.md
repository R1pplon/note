# 连接到特定进程

在这一步中，你将学习如何连接到容器内的特定进程。

## 目标

连接到 `my-nginx` 容器内的 `nginx` 进程。

## 结果示例

以下是你在此步骤结束时应该能够实现的目标：

1. 打开终端或命令行提示符。

2. 重启 `my-nginx` 容器。

验证 `my-nginx` 容器是否正在运行。

```
labex:~/ $ docker ps
CONTAINER ID   IMAGE     COMMAND                  CREATED          STATUS         PORTS     NAMES
e370ef667e69   nginx     "/docker-entrypoint.…"   11 minutes ago   Up 3 seconds   80/tcp    my-nginx
```

3. 运行 `docker ps` 命令获取 `my-nginx` 容器 ID。

```
labex:~/ $ docker ps -qf "name=<container_name>"
e370ef667e69
```

将 `<container_name>` 替换为实际的容器名称。

4. 运行 `docker exec` 命令连接到容器内的 `nginx` 进程。

```
labex:~/ $ docker exec -it <container_id> nginx -s reload
2024/01/20 09:34:25 [notice] 23#23: signal process started
```

将 `<container_id>` 替换为实际的容器 ID。

## 要求

- 你的机器上必须安装 Docker。

- 容器必须处于运行状态。
