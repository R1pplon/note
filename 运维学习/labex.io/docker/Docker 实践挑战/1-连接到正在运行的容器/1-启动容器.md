# 启动容器

在这一步中，你将学习如何使用 `docker run` 命令启动一个容器。

## 目标

从 `nginx` 镜像启动一个新容器。

## 结果示例

以下是你在此步骤结束时应该能够实现的目标：

1. 打开终端或命令行提示符。

2. 运行 `docker run` 命令启动一个名为 `my-nginx` 的新容器：

```
labex:~/ $ docker ps | grep my-nginx
e370ef667e69   nginx     "/docker-entrypoint.…"   27 seconds ago   Up 24 seconds   80/tcp    my-nginx
```

## 要求

- 你的机器上必须安装 Docker。
