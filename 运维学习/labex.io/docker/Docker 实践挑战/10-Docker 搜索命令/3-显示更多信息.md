# 显示更多信息

在这一步中，你将使用 `docker search` 命令在 Docker Hub 注册表中搜索一个镜像，并显示搜索结果的更多信息。

## 目标

- 在 Docker Hub 注册表中搜索 `alpine` 镜像，并显示搜索结果的更多信息。

## 示例

以下是你应在本步骤结束时能够完成的操作示例：

1. 在你的本地系统上打开一个终端或命令行界面。
2. 在 Docker Hub 注册表中搜索 `alpine` 镜像，并以表格格式显示名称、描述和星标数。

![docker search command example](https://file.labex.io/namespace/33fa8aba-d546-42e9-9692-64968aeaf0cc/docker/challenge-docker-search-command/zh/../assets/challenge-docker-search-command-3-1.png)

## 提示

你可以使用以下内容使结果以表格格式显示名称、描述和星标数：

```zsh
table {{.Name}}\t{{.Description}}\t{{.StarCount}}
```
