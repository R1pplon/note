# 显示最大搜索结果数量

在这一步中，你将使用 `docker search` 命令在 Docker Hub 注册表中搜索一个镜像，并显示最大搜索结果数量。

## 目标

- 在 Docker Hub 注册表中搜索 `alpine` 镜像，并按特定标准显示前 `5` 个搜索结果。

## 示例

以下是你应在本步骤结束时能够完成的操作示例：

1. 在你的本地系统上打开一个终端或命令行界面。
2. 在 Docker Hub 注册表中搜索 `alpine` 镜像，并以表格形式显示搜索结果的前 `5` 个数据，包括名称、描述和星标数。
