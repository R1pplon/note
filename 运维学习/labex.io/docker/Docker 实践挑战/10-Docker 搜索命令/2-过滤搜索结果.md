# 过滤搜索结果

在这一步中，你将使用 `docker search` 命令在 Docker Hub 注册表中搜索一个镜像，但会指定更具体的搜索条件进行过滤。

## 目标

- 在 Docker Hub 注册表中搜索 `alpine` 镜像，并通过指定额外的搜索条件来过滤搜索结果。

## 示例

以下是你应在本步骤结束时能够完成的操作示例：

1. 在你的本地系统上打开一个终端或命令行界面。
2. 在 Docker Hub 注册表中搜索 `alpine` 镜像，但只返回官方镜像。
