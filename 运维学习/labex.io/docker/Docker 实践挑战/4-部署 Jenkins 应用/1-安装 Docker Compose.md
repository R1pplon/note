# 安装 Docker Compose

Docker Compose 是一个用于定义和运行多容器 Docker 应用的工具。要使用 Docker 部署 Jenkins，你需要安装 Docker Compose。
在本实验中，请安装独立的 `docker-compose` 二进制文件，以便在后续检查中使用 `docker-compose` 命令。

## 目标

安装独立的 `docker-compose` 命令。

## 结果示例

Docker Compose 安装成功。

```
labex:~/ $ docker-compose --version
docker-compose version 1.29.2, build unknown
```
