# 将端口映射到随机端口

在这一步中，你将学习如何使用 `docker run` 命令将端口映射到随机端口。

## 目标

为 `my-nginx3` 容器将端口 `8080` 映射到随机端口。

## 结果示例

这是你在本步骤结束时应能完成的示例：

1. 打开终端或命令提示符。
2. 为 `my-nginx3` 容器将端口 `8080` 映射到随机端口。

```
labex:~/ $ docker ps | grep nginx3
5e1f6265d7ff   nginx     "/docker-entrypoint.…"   2 minutes ago    Up 2 minutes    80/tcp, 0.0.0.0:49153->8080/tcp, :::49153->8080/tcp   my-nginx3
```
