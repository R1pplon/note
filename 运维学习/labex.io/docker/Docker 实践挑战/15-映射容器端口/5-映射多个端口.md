# 映射多个端口

在这一步中，你将学习如何使用 `docker run` 命令映射多个端口。

## 目标

为 `my-nginx4` 容器将端口 `8080` 映射到端口 `80`，并将端口 `8443` 映射到端口 `443`。

## 结果示例

这是你在本步骤结束时应能完成的示例：

1. 打开终端或命令提示符。
2. 为 `my-nginx4` 容器将端口 `8080` 映射到端口 `80`，并将端口 `8443` 映射到端口 `443`。

```
labex:~/ $ docker ps | grep nginx4
44a44c2cf4c8   nginx     "/docker-entrypoint.…"   17 seconds ago   Up 16 seconds   80/tcp, 0.0.0.0:80->8080/tcp, :::80->8080/tcp, 0.0.0.0:443->8443/tcp, :::443->8443/tcp   my-nginx4
```
