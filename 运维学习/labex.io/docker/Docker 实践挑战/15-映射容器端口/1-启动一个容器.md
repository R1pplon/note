# 启动一个容器

在这一步中，你将学习如何使用 `docker run` 命令启动一个容器。

## 目标

从 `nginx` 镜像启动一个新的容器。

## 结果示例

这是你在本步骤结束时应能完成的示例：

1. 打开终端或命令提示符。
2. 运行 `docker run` 命令来运行一个名为 `my-nginx` 的新容器。

```
labex:~/ $ docker ps
CONTAINER ID   IMAGE     COMMAND                  CREATED          STATUS          PORTS     NAMES
ff47448d1f1e   nginx     "/docker-entrypoint.…"   21 seconds ago   Up 18 seconds   80/tcp    my-nginx
```
