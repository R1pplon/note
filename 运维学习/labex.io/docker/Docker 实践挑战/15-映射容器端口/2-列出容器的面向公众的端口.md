# 列出容器的面向公众的端口

在这一步中，你将学习如何使用 `docker inspect` 命令来列出容器面向公众的端口。

## 目标

使用 `docker inspect` 命令列出 `my-nginx` 容器的面向公众的端口。

## 结果示例

这是你在本步骤结束时应能完成的示例：

1. 打开终端或命令提示符。
2. 列出 `my-nginx` 容器的面向公众的端口。

```
"Domainname": "",
"User": "",
"AttachStdin": false,
"AttachStdout": false,
"AttachStderr": false,
"ExposedPorts": {
    "80/tcp": {}
},
"Tty": true,
"OpenStdin": true,
"StdinOnce": false,
```

## 要求

- 容器必须正在运行。
