# 介绍

Docker 的本质是利用 LXC 来实现类似虚拟机的功能，从而节省硬件资源并为用户提供更多计算资源。本项目将 C++ 与 Linux 的命名空间（Namespace）和控制组（Control Group）技术相结合，实现一个简单的 Docker 容器。

最后，我们将为容器实现以下功能：

1. 独立的文件系统
2. 支持网络访问
