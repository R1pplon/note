# 额外的打标

在这一步中，你将继续你的打标工作，以进一步展示你的 Docker 技能。

## 任务

- 将 `ubuntu` 镜像标记为 `my-ubuntu:latest`。
- 将 `python` 镜像标记为 `my-python:v3.9`。

## 要求

对于此打标过程，请遵循与步骤 1 相同的要求。

## 示例

成功完成后，Docker 镜像列表应显示新创建的标签。

```
labex:~/ $ docker images
REPOSITORY                    TAG       IMAGE ID       CREATED         SIZE
my-ubuntu                     latest    e34e831650c1   2 weeks ago     77.9MB
ubuntu                        latest    e34e831650c1   2 weeks ago     77.9MB
my-python                     v3.9      e7177b0afd0e   5 weeks ago     1.02GB
python                        latest    e7177b0afd0e   5 weeks ago     1.02GB
...
```
