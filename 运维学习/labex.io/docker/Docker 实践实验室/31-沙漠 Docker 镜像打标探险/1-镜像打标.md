# 镜像打标

在这一步中，你将承担使用 Docker 为镜像打标的任务，以促进其在系统内的组织管理和识别。

## 任务

- 将现有的 `nginx` 镜像标记为 `my-nginx:latest`。
- 将 `alpine` 镜像标记为 `my-alpine:v1.0`。

## 要求

你需要在 zsh 终端中使用 Linux 环境执行以下操作：

- 使用 Markdown 行内代码格式来指定文件名和路径。
- 使用带有语言类型标签的 Markdown 代码块格式来指定命令执行路径。

## 示例

完成打标过程后，你应该能在 Docker 环境中看到新标记的镜像列表。

```
labex:~/ $ docker images
REPOSITORY                    TAG       IMAGE ID       CREATED         SIZE
alpine                        latest    05455a08881e   14 hours ago    7.38MB
my-alpine                     v1.0      05455a08881e   14 hours ago    7.38MB
my-nginx                      latest    a8758716bb6a   3 months ago    187MB
nginx                         latest    a8758716bb6a   3 months ago    187MB
...
```
