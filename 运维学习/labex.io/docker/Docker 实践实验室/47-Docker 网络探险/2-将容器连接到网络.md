# 将容器连接到网络

在此步骤中，你将把代表街头艺人团体的 Docker 容器连接到相应的网络中。

## 任务

1. 在 `north_group` 网络上创建一个名为 `north` 的容器。
2. 在 `south_group` 网络上创建一个名为 `south` 的容器。
3. 将这两个容器都连接到 `performers_net` 桥接网络。

## 要求

- 在 `/home/labex/project` 目录下执行所有任务。
- 使用长时间运行的容器，以便在它们启动后检查其网络配置。

## 示例

查看容器：

```
labex:~/ $ docker ps
CONTAINER ID   IMAGE     COMMAND        CREATED          STATUS          PORTS     NAMES
a9a062d4c1e9   busybox   "sleep 3600"   34 seconds ago   Up 33 seconds             north
abf9d4d787d3   busybox   "sleep 3600"   34 seconds ago   Up 34 seconds             south
```

通过 `docker container inspect <container_id>` 查看连接情况：

```
docker container inspect north
...
"Networks": {
    "north_group": {
        "IPAMConfig": null,
        "Links": null,
...
    },
    "performers_net": {
        "IPAMConfig": {},
        "Links": null,
...
```
