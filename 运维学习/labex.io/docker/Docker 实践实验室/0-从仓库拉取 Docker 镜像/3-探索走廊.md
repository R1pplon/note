# 探索走廊

在 Docker 迷宫的中心，你会发现自己身处一个十字路口，周围环绕着通往不同领域的走廊。你的下一个任务是通过启动你的 Docker 容器来穿过这些走廊。这一步类似于从你拉取的镜像运行容器的过程，开启一段穿越容器化环境复杂走廊的旅程。

## 释放容器能量

```bash
docker run -it --name <container_name> <map_image> <command>
```

执行 `docker run` 命令，为你的容器启动做好准备。`-it` 标志授予你交互式访问权限，使你能够无缝地探索容器走廊。将 `<container_name>` 替换为一个与你的任务产生共鸣的名称，并将 `<command>` 替换为你希望容器运行的正确的 `Linux shell` 命令，使你的容器成为这个浩瀚 Docker 迷宫中一个可识别的实体。

在这一步中，你必须运行一个名为 `alpine_container` 的容器，并让它执行 `/bin/sh` 命令。你可以在终端中执行以下命令：

```bash
docker run -it --name alpine_container alpine /bin/sh
```

## 示例

如果你正确运行该命令，输出必须如下所示：

```shell
$ docker run -it --name alpine_container alpine /bin/sh
/ # ls -a
. .dockerenv dev home media opt root sbin sys usr
.. bin etc lib mnt proc run srv tmp var
/ #
```
