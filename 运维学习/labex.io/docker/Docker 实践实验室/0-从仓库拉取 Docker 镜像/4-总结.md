# 总结

在 Docker 迷宫的中心，你发现自己站在一个十字路口，周围是通往不同领域的走廊。你的下一个任务是通过启动 Docker 容器来穿越这些走廊。这一步类似于从你拉取的镜像中运行容器，开启一段穿越容器化环境复杂走廊的旅程。

## 释放容器能量

```bash
docker run -it --name <container_name> <map_image> <command>
```

执行 `docker run` 命令，为你的容器启动做好准备。`-it` 标志为你提供了交互式访问权限，使你能够无缝地导航容器走廊。将 `<container_name>` 替换为与你的任务相符的名称，并将 `<command>` 替换为你希望容器运行的正确的 `Linux shell 命令`，使你的容器在这个广阔的 Docker 迷宫中成为一个可识别的实体。

在这一步中，你需要运行一个名为 `alpine_container` 的容器，并让它执行 `/bin/sh` 命令。你可以在终端中执行以下命令：

```bash
docker run -it --name alpine_container alpine /bin/sh
```

## 示例

如果你正确运行命令，输出应该如下所示：

```shell
$ docker run -it --name alpine_container alpine /bin/sh
/ # ls -a
. .dockerenv dev home media opt root sbin sys usr
.. bin etc lib mnt proc run srv tmp var
/ #
```
