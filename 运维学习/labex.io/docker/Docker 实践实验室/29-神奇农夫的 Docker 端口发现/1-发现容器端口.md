# 发现容器端口

在这一步中，目标是了解如何列出 Docker 容器正在暴露的端口。

## 任务

- 创建 Nginx 容器，并将端口 8080 映射到容器的端口 80。
- 创建 Alpine 容器，并将端口 81 映射到容器的端口 80。
- 列出「nginx」Docker 容器暴露的端口。
- 识别「alpine」Docker 容器暴露的端口。

## 要求

- 确保 Docker 已正确安装并在你的系统上运行。
- 使用默认工作目录：`/home/labex/project` 和相对路径：`~/project`。

## 示例

通过运行显示容器的命令，你可以获得运行中容器的列表及其暴露的端口。

```
CONTAINER ID   IMAGE     COMMAND                  CREATED          STATUS          PORTS                                   NAMES
8781d6059982   alpine    "sleep 3600"             41 seconds ago   Up 39 seconds   0.0.0.0:81->80/tcp, :::81->80/tcp       kind_curran
0ae4b3d81bc4   nginx     "/docker-entrypoint.…"   50 seconds ago   Up 45 seconds   0.0.0.0:8080->80/tcp, :::8080->80/tcp   quizzical_zhukovsky
```
