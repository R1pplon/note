# 探索端口映射

在这一步中，目标是了解如何查看特定容器的端口映射情况。

## 任务

- 创建一个名为 `my-nginx` 的 Nginx 容器，并将端口 8081 映射到容器的端口 80。
- 创建一个名为 `my-ubuntu` 的 Ubuntu 容器，并将端口 5000 映射到容器的端口 80。
- 显示「nginx」容器的端口映射。
- 探索「ubuntu」容器的端口映射。

## 要求

- 使用步骤 1 中指定的默认工作目录和相对路径。

## 示例

运行该命令可以提供容器特定的端口映射信息。

```
# my-ubuntu port
80/tcp -> 0.0.0.0:5000
80/tcp -> :::5000
# my-nginx port
80/tcp -> 0.0.0.0:8081
80/tcp -> :::8081
```
