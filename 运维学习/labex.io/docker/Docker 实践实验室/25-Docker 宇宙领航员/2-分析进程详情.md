# 分析进程详情

## 任务

- 查看进程详情，包括 PID、用户、命令以及 CPU/内存使用情况，并将结果保存到 `/home/labex/project/process_details.txt`。
- 识别消耗资源最多的进程，并将结果保存到 `/home/labex/project/process_res.txt`。

## 示例

结果必须如下所示：

```bash
# 获取容器内正在运行的进程的详细信息
$ cat /home/labex/project/process_details.txt
USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
root 2115 0.0 0.0 2792 1036 ? Ss 11:06 0:00 sleep infinity

# 获取消耗系统资源最多的前置进程
$ cat /home/labex/project/process_res.txt
ae229ed67e17 test_container 0.00% 320KiB / 3.505GiB 0.01% 5.88kB / 0B 0B / 0B 1
```
