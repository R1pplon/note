# 探索容器的进程

## 任务

- 识别 Docker 容器 `test_container` 内正在运行的进程，并将结果保存到 `/home/labex/project/process_info.txt`。
- 显示 `test_container` 中消耗系统资源最多的前置进程，并将结果保存到 `/home/labex/project/process_top.txt`。

## 示例

结果必须如下所示：

```bash
# 识别正在运行的进程
$ cat /home/labex/project/process_info.txt
UID PID PPID C STIME TTY TIME CMD
root 2115 2093 0 11:06 ? 00:00:00 sleep infinity

# 显示消耗系统资源最多的前置进程
$ cat /home/labex/project/process_top.txt
CONTAINER ID NAME CPU % MEM USAGE / LIMIT MEM % NET I/O BLOCK I/O PIDS
ae229ed67e17 test_container 0.00% 320KiB / 3.505GiB 0.01% 5.74kB / 0B 0B / 0B 1
```
