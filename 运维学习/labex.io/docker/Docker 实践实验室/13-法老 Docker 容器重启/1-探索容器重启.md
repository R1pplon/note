# 探索容器重启

## 任务

- 探索容器的 Docker 重启策略选项。
- 应用 `--restart` 标志来重启容器 `nginx_demo`。
- 检查重启后容器的状态。

## 示例

完成后，容器 `nginx_demo` 应已重启，并且应验证其状态。

```bash
$ docker ps --filter "ancestor=nginx"
CONTAINER ID IMAGE COMMAND CREATED STATUS PORTS NAMES
bfa878ff0258 nginx:latest "/docker-entrypoint.…" 34 seconds ago Up 4 seconds 80/tcp nginx_demo
```
