# 探索 Docker 信息

在这一步中，你将深入 Docker 挑战的第一层，探索通过 `docker info` 命令可获得的基本信息。

## 任务

- 执行命令以显示 Docker 系统级信息。
- 识别并列出系统级信息中呈现的关键组件和细节。

## 要求

- 你需要在 Linux 环境中进行操作。
- 本次挑战的默认工作目录是 `/home/labex/project`。

## 示例

在终端中执行显示 Docker 信息的命令后，你将收到 Docker 系统级信息的详细概述。

```
Client:
 Context:    default
 Debug Mode: false

Server:
 Containers: 2
  Running: 0
  Paused: 0
  ...
```
