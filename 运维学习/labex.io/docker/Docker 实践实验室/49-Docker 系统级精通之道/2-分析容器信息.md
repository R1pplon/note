# 分析容器信息

在这一步中，你将继续分析 Docker 环境中特定于容器的详细信息。

## 任务

- 显示所有正在运行的容器的详细信息。
- 识别有关正在运行的容器的关键数据点。

## 要求

- 你应该使用 Docker 命令行界面。
- 确保命令在 `/home/labex/project` 目录下执行。

## 示例

执行特殊命令将为你提供正在运行的容器和相关细节的概述。

```
CONTAINER ID   IMAGE     COMMAND        CREATED          STATUS          PORTS     NAMES
a22f8728641d   busybox   "sleep 3600"   2 seconds ago    Up 1 second               affectionate_varahamihira
c33079072a7b   alpine    "sleep 3600"   41 seconds ago   Up 40 seconds             nifty_wilbur
```
