# 探索运行中的容器

在这一步中，你将踏上旅程，探索 Docker 星系中正在运行的容器。

## 任务

- 列出 Docker 环境中所有正在运行的容器，并将结果写入文件 `/home/labex/project/container.txt`。
- 检索运行中容器的详细信息，例如它们的名称、ID 和状态，并将结果写入文件 `/home/labex/project/container_format.txt`。

## 要求

- 你必须检索运行中容器的信息，并将结果写入 `/home/labex/project` 目录下的文件中。
- 确保 Docker 环境可访问且已正确设置，以便执行命令。

## 示例

如果挑战完成正确，你将看到 `container.txt` 的内容如下所示：

```bash
$ cat container.txt
CONTAINER ID IMAGE COMMAND CREATED STATUS PORTS NAMES
f62c57f2a3ec jenkins/jenkins "/usr/bin/tini -- /u…" 7 months ago Up 46 seconds 0.0.0.0:8080- :::8080- 0.0.0.0:50000- :::50000- jenkins > 8080/tcp, > 8080/tcp, > 50000/tcp, > 50000/tcp
```

`container_format.txt` 的内容如下所示：

```bash
$ cat container_format.txt
CONTAINER ID NAMES STATUS
f62c57f2a3ec jenkins Up 3 minutes
```
