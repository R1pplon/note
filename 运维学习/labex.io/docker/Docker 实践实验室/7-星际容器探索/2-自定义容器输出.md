# 自定义容器输出

在这一步中，你将深入研究正在运行的容器，并根据你的探索需求自定义输出。

## 任务

- 修改命令的输出，以显示额外的详细信息，例如容器 ID、镜像、名称、端口、创建时间和状态，然后通过 `:` 分割结果，并写入 `/home/labex/project/container_details.txt`。

## 示例

如果挑战完成正确，你将看到 `container_details.txt` 的内容如下所示：

```bash
$ cat /home/labex/project/container_details.txt
f62c57f2a3ec: jenkins/jenkins: jenkins: 0.0.0.0:8080- :::8080- 0.0.0.0:50000- :::50000- 2023-05-30 16:44:13 +0800 CST: Up 22 minutes > 8080/tcp, > 8080/tcp, > 50000/tcp, > 50000/tcp:
```
