# 为 Nginx 镜像创建基础 Dockerfile

## 任务

- 创建一个用于构建 Nginx 镜像的 Dockerfile。
- 在 Dockerfile 中定义必要的配置和指令。

## 要求

- 使用该 Dockerfile 构建一个 Nginx 镜像。
- Dockerfile 必须存放在 `/home/labex/project` 目录下。

## 示例

一旦 Dockerfile 创建并配置完成，应能成功使用它构建出 Nginx 镜像。

```
labex:project/ $ pwd
/home/labex/project
labex:project/ $ ll
total 4.0K
-rw-r--r-- 1 labex labex 11 Jan 26 16:53 Dockerfile
```
