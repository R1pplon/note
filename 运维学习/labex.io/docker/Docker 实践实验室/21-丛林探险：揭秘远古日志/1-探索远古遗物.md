# 探索远古遗物

## 任务

- 查看名为 `ancient-artifact` 的 Docker 容器日志
- 识别日志中任何关键的错误信息（critical error messages）
- 将这些关键错误日志保存到 `/home/labex/project` 目录下的 `critical_log.txt` 文件中

## 示例

查看日志后，你应该能够识别出与连接问题或配置错误相关的错误信息。

