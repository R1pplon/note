# 分析历史文献

## 任务

- 从名为 `ancient-artifact` 的容器日志中提取时间戳，以便进行进一步分析
- 确定日志中特定事件发生的频率
- 将带有时间戳的日志保存到 `/home/labex/project` 目录下的 `timestamp_log.txt` 文件中

## 要求

- 使用 Shell 命令解析并从日志中提取时间戳
- 调查日志条目以识别重大事件的发生情况
- 文件必须保存到 `/home/labex/project` 目录，文件名为 `timestamp_log.txt`
