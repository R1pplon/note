# 筛选和优化搜索结果

## 任务

- 优化搜索，仅显示官方 Docker 镜像。
- 显示评分最高的 "nginx" 官方 Docker 镜像的详细信息。

## 要求

- 使用 Docker 命令行界面将搜索结果筛选为仅显示官方镜像。
- 检索评分最高的官方 "nginx" 镜像的详细信息。
- 你需要的命令满足以下格式要求：

  ```
  docker search --filter=<filter-type>=<filter-scope> nginx
  ```

## 示例

在终端中运行以下命令来筛选搜索结果并显示评分最高的 "nginx" 官方镜像：

```
NAME      DESCRIPTION                                     STARS     OFFICIAL   AUTOMATED
nginx     Official build of Nginx.                        19536     [OK]
unit      Official build of NGINX Unit: Universal Web …   20        [OK]
```
