# 搜索镜像

## 任务

- 在仓库中搜索名为 "nginx" 的特定 Docker 镜像。
- 检索 "nginx" 镜像的详细信息，包括其标签（tag）和描述。

## 要求

- 使用 Docker 命令行界面搜索所需的镜像。
