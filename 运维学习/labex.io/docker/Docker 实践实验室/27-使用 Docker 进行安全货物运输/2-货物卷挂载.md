# 货物卷挂载

在这一步中，目标是确保货物处理脚本能够访问必要的货物数据。

## 任务

- 将本地目录 `/home/labex/project` 挂载到容器路径 `/cargo/data`
- 确保容器中包含特定的货物处理脚本 `handle_cargo.sh`
- 验证货物处理脚本对挂载的卷具有读写权限

## 示例

```bash
$ docker exec cargo-container test -e /cargo/data/handle_cargo.sh && echo "true" || echo "false"
true

$ docker inspect -f '{{ range .Mounts }}{{ .Source }}:{{ .Destination }} {{ end }}' cargo-container
/home/labex/project:/cargo/data

$ docker exec cargo-container /bin/bash -c "/cargo/data/handle_cargo.sh && touch /cargo/data/test_file && rm /cargo/data/test_file && echo 'success'" || echo 'failure'
Hello, World!
success
```
