# 容器创建

在这一步中，目标是创建一个 Docker 容器，并确保它满足货物运输的特定要求。

## 任务

- 创建一个名为 `cargo-container` 的 Docker 容器
- 确保容器中包含特定的货物处理脚本
- 确保容器配置为使用有限的系统资源

## 要求

- 货物处理脚本应位于容器内的 `/cargo/scripts/handle_cargo.sh`
- 配置容器，使其最多使用 512MB 内存和 1 个 CPU 核心

## 示例

```bash
$ docker inspect -f '{{.HostConfig.Memory}}' cargo-container
536870912

$ docker inspect -f '{{.HostConfig.NanoCpus}}' cargo-container
1000000000

$ docker exec cargo-container test -e /cargo/scripts/handle_cargo.sh && echo "true" || echo "false"
true
```
