# 将数据传输到外部世界

在这一步中，你需要将数据从 Docker 容器传输到外部世界。

## 任务

- 在宿主机上创建目录 `/home/labex/project/data`。
- 将 Docker 容器中 `/app/data` 下的 `data.txt` 文件复制到宿主机的 `/home/labex/project/data/data.txt` 路径下。

## 示例

Docker 容器结构：

```
labex:project/ $ docker exec my-nginx ls /app/data/data.txt
```

宿主机目录结构：

```
labex:project/ $ tree
.
├── data
│   └── data.txt
└── demon
    └── data
        └── data.txt

3 directories, 2 files
```
