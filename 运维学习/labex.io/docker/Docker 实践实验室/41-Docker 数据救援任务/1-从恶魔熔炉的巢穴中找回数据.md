# 从恶魔熔炉的巢穴中找回数据

在这一步中，你需要从恶魔熔炉的巢穴中找回数据，并将其复制到你的 Docker 容器中。

## 任务

- 为本次挑战创建一个名为 `my-nginx` 的容器。
- 使用宿主机 `/home/labex/project/demon/data` 目录下现有的 `data.txt` 文件。
- 在名为 `my-nginx` 的 Docker 容器内创建目录 `/app/data`。
- 将 `data.txt` 文件复制到名为 `my-nginx` 的 Docker 容器内的 `/app/data/data.txt` 路径下。

## 要求

- 你需要在 Linux 环境下进行操作。
- 终端的默认工作目录为 `/home/labex/project`。

## 示例

宿主机目录结构：

```
labex:project/ $ pwd
/home/labex/project
labex:project/ $ tree
.
└── demon
    └── data
        └── data.txt

2 directories, 1 file
```

Docker 容器结构：

```
labex:project/ $ docker exec my-nginx ls /app/data/data.txt
```
