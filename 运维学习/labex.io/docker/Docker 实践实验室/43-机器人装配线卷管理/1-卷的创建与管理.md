# 卷的创建与管理

在这一步中，你将创建和管理 Docker 卷，用于存储机器人装配线的关键数据和配置。

## 任务

- 创建一个名为 "robot_data" 的 Docker 卷，用于存储机器人装配线的数据。
- 确保该卷是持久化的，并且可以被多个容器访问。

## 要求

- 使用 Docker 命令行界面。
- 确保卷是以指定的名称 "robot_data" 创建的。
- 该卷应能被主机上运行的任何容器访问。

## 示例

你应该能够使用命令 `docker volume ls` 列出卷，并在其中看到 "robot_data" 卷。

```
labex:~/ $ docker volume ls
DRIVER    VOLUME NAME
local     jenkins-data
local     minikube
local     robot_data
```
