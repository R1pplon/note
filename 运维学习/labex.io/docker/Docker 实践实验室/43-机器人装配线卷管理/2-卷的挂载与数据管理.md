# 卷的挂载与数据管理

在这一步中，你将把已创建的卷挂载到一个容器中，并在该卷内管理数据。

## 任务

- 启动一个名为 "nginx-server" 的新 Nginx 容器，并将 "robot_data" 卷挂载到路径 "/usr/share/nginx/html"。
- 在挂载的卷中创建一个名为 "index.html" 的新 HTML 文件，内容为 "Robots are the future!"。

## 要求

- 使用 Docker 命令行界面进行容器管理。
- 确保卷已正确挂载到 Nginx 容器。

## 示例

完成任务后，访问 Nginx 服务器应能显示 HTML 内容 "Robots are the future!"。
