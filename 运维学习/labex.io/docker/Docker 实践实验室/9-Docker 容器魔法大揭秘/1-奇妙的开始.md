# 奇妙的开始

在这个步骤中，你将踏入 Docker 容器世界的旅程。

## 任务

- 使用 Ubuntu 镜像启动一个名为 "magical-painting" 的 Docker 容器。
- 确保该容器正在运行并可供交互。

## 示例

```bash
# 检查容器是否正在运行
$ docker container ps --format "{{.Names}} {{.Status}} {{.CreatedAt}}"
magical-painting Up 41 seconds 2024-01-26 13:10:53 +0800 CST

# 与容器进行交互
$ docker container exec -it magical-painting /bin/sh
$ echo "Hello, Docker"
Hello, Docker
```
