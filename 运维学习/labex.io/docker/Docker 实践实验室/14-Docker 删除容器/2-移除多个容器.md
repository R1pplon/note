# 移除多个容器

在这一步中，你将通过学习使用 `docker rm` 命令一次性移除多个 Docker 容器来提升你的技能。幽灵导师将引导你完成这一过程。

#### 示例代码

首先，运行以下命令创建名为 `mycontainer` 的容器：

```zsh
docker run --name container1 alpine:latest
docker run --name container2 alpine:latest
docker run --name container3 alpine:latest
```

运行以下命令一次性移除多个容器：

```zsh
docker rm container1 container2 container3
```
