# 添加 Shebang 并初始化数组

现在，让我们开始编写脚本，添加 Shebang 并初始化数组。

1. 将以下内容添加到 `array-comparison.sh` 中：

```bash
#!/bin/bash

# Initialize the arrays
a=(3 5 8 10 6)
b=(6 5 4 12)
c=(14 7 5 7)
```

让我们来分析一下这段代码：

- 第一行 `#!/bin/bash` 被称为 Shebang。它告诉系统使用 Bash 解释器来运行此脚本。这一行对于任何 Shell 脚本都至关重要。
- 随后我们初始化了三个数组：`a`、`b` 和 `c`。在 Bash 中，数组通过将元素括在圆括号 `()` 中并用空格分隔来定义。
- 每个数组包含不同的整数值。我们将使用这些数组来查找共同元素。
