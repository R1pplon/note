# 介绍

本实验将引导你创建一个简单的 Shell 脚本，用于打印经典的「Hello, World!」消息。你将学习使用 Bash（Bourne Again SHell）进行 Shell 编程的基础知识，Bash 是 Linux 等类 Unix 操作系统中广泛使用的工具。本实验专为初学者设计，所以如果你是编程或命令行的新手，也不必担心。
