# 执行脚本

现在脚本已经具备了执行权限，我们可以运行它了。要运行当前目录下的脚本，我们在脚本名前加上 `./`。这个 `./` 告诉系统在当前目录中查找该脚本。

在终端中输入以下命令并按回车：

```bash
./hello.sh
```

如果一切操作正确，你应该会看到如下输出：

```
Hello, World!
```
