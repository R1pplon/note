# 创建你的第一个脚本

让我们从创建一个简单的 Shell 脚本开始，以此来演示特殊变量的使用。

1. 在 WebIDE 中打开终端。你应该能看到一个等待输入的命令行提示符。

2. 切换到项目目录：

```bash
cd ~/project
```

此命令将当前目录更改为 `~/project`，这是你本实验的默认工作目录。

3. 使用以下命令创建一个名为 `special_vars.sh` 的新文件：

```bash
touch special_vars.sh
```

`touch` 命令会在文件不存在时创建一个空文件，如果文件已存在则更新其时间戳。

4. 在 WebIDE 编辑器中打开该文件。你可以通过点击屏幕左侧文件浏览器中的文件名来完成此操作。

5. 将以下内容添加到文件中：

```bash
#!/bin/bash

echo "Script Name: $0"
echo "First Argument: $1"
echo "Second Argument: $2"
echo "All Arguments: $@"
echo "Number of Arguments: $#"
echo "Process ID: $$"
```

让我们逐行解析每一项的作用：

- `#!/bin/bash`：这被称为 Shebang。它告诉系统使用 bash 来解释执行此脚本。
- `$0`：这个特殊变量保存了脚本的名称。
- `$1` 和 `$2`：分别代表第一个和第二个命令行参数。
- `$@`：代表传递给脚本的所有命令行参数。
- `$#`：提供命令行参数的总数。
- `$$`：提供当前 Shell 的进程 ID（PID）。

6. 添加内容后保存文件。

7. 在终端运行以下命令，为脚本添加执行权限：

```bash
chmod +x special_vars.sh
```

`chmod` 命令用于更改文件权限。`+x` 选项增加了执行权限，允许你运行该脚本。
