# 带有参数的函数

既然我们已经创建了一个基础函数，现在让我们通过添加参数使其更加灵活。参数允许我们将信息传递到函数中。

再次打开 `functions.sh` 文件，并将内容替换为以下代码：

```bash
#!/bin/bash

# 带有参数的函数
greet() {
  echo "Hello, $1!"
}

# 带有多个参数的函数
calculate() {
  echo "The sum of $1 and $2 is $(($1 + $2))"
}

# 使用参数调用函数
greet "Alice"
calculate 5 3
```

让我们审视这段代码：

- 在 `greet` 函数中，`$1` 指代传递给函数的第一个参数。
- 在 `calculate` 函数中，`$1` 和 `$2` 分别指代第一个和第二个参数。
- `$(($1 + $2))` 执行两个参数的算术加法。

运行脚本：

```bash
./functions.sh
```

你应该会看到：

```
Hello, Alice!
The sum of 5 and 3 is 8
```

如果你没有看到这个输出，请确保你已正确保存了对文件的更改。
