# 总结

在本实验中，你学习了如何在 Shell 脚本中比较数组。你创建了一个脚本，利用嵌套循环和条件语句在三个数组中查找共同元素。通过这个练习，你掌握了 Shell 脚本中的核心概念，包括：

2. 使用嵌套循环比较数组元素
3. 使用条件语句检查相等性
4. 动态地向数组添加元素
5. 使脚本具有可执行权限并运行它
