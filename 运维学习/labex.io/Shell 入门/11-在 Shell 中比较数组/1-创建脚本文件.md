# 创建脚本文件

首先，让我们为脚本创建一个新文件。

1. 在 WebIDE 中打开终端。你应该看到一个以 `$` 符号结尾的命令提示符。

2. 切换到项目目录：

```bash
cd ~/project
```

此命令将当前目录更改为项目文件夹。`~` 符号代表你的家目录，而 `/project` 是其中的一个子文件夹。

3. 创建一个名为 `array-comparison.sh` 的新文件：

```bash
touch array-comparison.sh
```

`touch` 命令用于创建一个空文件。如果文件已经存在，它会更新文件的时间戳而不修改其内容。

4. 在 WebIDE 编辑器中打开该文件。你可以通过点击 WebIDE 界面左侧文件浏览器中的文件名来完成此操作。
