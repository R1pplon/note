# 测试文件是否存在

现在我们已经创建了一个文件，让我们学习如何检查文件是否存在。这是 Shell 脚本中的一项常见任务，尤其是当你需要对文件执行操作时。

1. 创建一个名为 `file_exists.sh` 的新脚本文件：

   ```bash
   touch file_exists.sh
   ```

2. 向文件中添加以下内容：

   ```bash
   #!/bin/bash
   
   filename="test_file.txt"
   if [ -e "$filename" ]; then
     echo "$filename exists"
   else
     echo "$filename does not exist"
   fi
   ```

   让我们来分解一下这段代码：

   - `#!/bin/bash` 被称为 Shebang。它告诉系统这是一个 Bash 脚本。
   - 我们将变量 `filename` 设置为 `test_file.txt`。
   - `if` 语句检查文件是否存在。`-e` 是一个测试项，如果文件存在则返回真。
   - 我们使用 `echo` 根据文件是否存在来打印消息。

3. 保存文件并退出编辑器。

4. 为脚本添加执行权限：

   ```bash
   chmod +x file_exists.sh
   ```

5. 运行脚本：

   ```bash
   ./file_exists.sh
   ```

   你应该会看到输出：「test_file.txt exists」

6. 现在，让我们用一个不存在的文件进行测试。首先，重命名我们的测试文件：

   ```bash
   mv test_file.txt non_existent.txt
   ```

   此命令将 `test_file.txt` 重命名为 `non_existent.txt`。

7. 修改脚本以检查原始文件名 `test_file.txt`：

   ```bash
   nano file_exists.sh
   ```

   如果 `filename` 变量尚未设置为 `test_file.txt`，请将其更改为该值。

8. 再次运行脚本：

   ```bash
   ./file_exists.sh
   ```

   你应该会看到输出：「test_file.txt does not exist」

这个脚本演示了如何检查文件是否存在，当你的脚本需要处理可能存在也可能不存在的文件时，这一点至关重要。
