# 测试目录是否存在

与测试文件是否存在类似，我们也可以检查目录是否存在。当你的脚本需要处理可能存在也可能不存在的目录时，这非常有用。

1. 创建一个名为 `dir_exists.sh` 的新脚本文件：

   ```bash
   touch dir_exists.sh
   ```

2. 向文件中添加以下内容：

   ```bash
   #!/bin/bash
   
   dirname="test_directory"
   if [ -d "$dirname" ]; then
     echo "$dirname exists"
   else
     echo "$dirname does not exist"
   fi
   ```

   这个脚本与我们的文件存在性脚本非常相似，但它使用的是 `-d` 而不是 `-e`。`-d` 测试专门用于检查目录是否存在。

3. 保存文件并退出编辑器。

4. 为脚本添加执行权限：

   ```bash
   chmod +x dir_exists.sh
   ```

5. 运行脚本：

   ```bash
   ./dir_exists.sh
   ```

   你应该会看到输出：「test_directory does not exist」

6. 现在，让我们创建目录并再次运行脚本：

   ```bash
   mkdir test_directory
   ./dir_exists.sh
   ```

   你现在应该会看到输出：「test_directory exists」

   `mkdir` 是创建新目录的命令。

这个脚本演示了如何检查目录是否存在。这在需要创建、修改或删除目录的脚本中特别有用。
