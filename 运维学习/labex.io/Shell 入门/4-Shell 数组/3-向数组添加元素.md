# 向数组添加元素

现在我们有了空数组，让我们向其中添加一些元素。

在 `arrays.sh` 文件中数组初始化的下方添加以下代码：

```bash
# 向 NUMBERS 数组添加元素
NUMBERS+=(1)
NUMBERS+=(2)
NUMBERS+=(3)

# 向 STRINGS 数组添加元素
STRINGS+=("hello")
STRINGS+=("world")

# 向 NAMES 数组添加元素
NAMES+=("John")
NAMES+=("Eric")
NAMES+=("Jessica")
```

这段代码的作用如下：

- 我们使用 `+=` 运算符向数组追加元素。
- 对于 `NUMBERS`，我们添加了整数 1、2 和 3。
- 对于 `STRINGS`，我们添加了单词「hello」和「world」。
- 对于 `NAMES`，我们添加了三个名字：「John」、「Eric」和「Jessica」。
- 请注意，我们将字符串元素括在引号中，但数字不需要引号。
