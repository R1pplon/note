# 总结

在本实验中，你学习了 Linux 进程管理的基本概念。你首先使用 `ps` 和 `top` 命令理解进程状态及其生命周期，观察进程如何在运行 (R)、可中断睡眠 (S) 和停止 (T) 等状态之间转换。你练习识别常见的进程状态，并解释 `ps aux` 和 `ps -ef` 的输出，从而深入了解系统进程。

此外，你探索了控制后台和前台作业的方法，这对于高效使用终端至关重要。你掌握了使用各种命令（例如 `kill`、`killall` 和 `pkill`）终止进程的方法，理解了它们在优雅终止或强制终止时的不同应用。最后，你学习了如何使用 `uptime` 和 `lscpu` 监控系统负载和 CPU 使用率，以及如何使用 `top` 分析详细的进程活动，从而全面了解系统性能和资源利用情况。
