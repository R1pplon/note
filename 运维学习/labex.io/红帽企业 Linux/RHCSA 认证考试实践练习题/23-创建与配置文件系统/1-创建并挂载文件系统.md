# 创建并挂载文件系统

在这一步骤中，你将对可用磁盘进行分区，并使用不同的文件系统格式化这些分区。然后，你需要将它们挂载到指定的目录，并确保它们在系统启动时能够自动挂载。

## 任务

- 对 `/dev/vdb` 磁盘进行分区，创建三个新分区。
- 在第一个分区上创建 `vfat` 文件系统。
- 在第二个分区上创建 `ext4` 文件系统。
- 在第三个分区上创建 `xfs` 文件系统。
- 将每个文件系统挂载到专用目录。
- 配置系统以在开机时自动挂载这些文件系统。

## 要求

- 使用 `/dev/vdb` 设备创建分区。
- 三个分区的大小应合理（例如，每个 1GB）。
- 将 `vfat` 文件系统挂载到 `/mnt/vfat`。
- 将 `ext4` 文件系统挂载到 `/mnt/ext4`。
- 将 `xfs` 文件系统挂载到 `/mnt/xfs`。
- 确保文件系统在系统启动时自动挂载。

## 示例

完成此步骤后，运行 `lsblk -f` 命令应显示 `/dev/vdb` 上的新分区及其各自的挂载点。输出结果应类似于：

```
$ lsblk -f
NAME   FSTYPE FSVER LABEL UUID                                 FSAVAIL FSUSE% MOUNTPOINTS
...
vdb
├─vdb1 vfat   FAT32       E6A1-5E45                              1022M     0% /mnt/vfat
├─vdb2 ext4   1.0         2a2e4d25-9988-4613-9a3b-558a3e7a0e7f    938M     0% /mnt/ext4
└─vdb3 xfs                 7b3e0e6b-1d73-4ea2-8a9d-16a81e3e7b1c  1018M     1% /mnt/xfs
```
