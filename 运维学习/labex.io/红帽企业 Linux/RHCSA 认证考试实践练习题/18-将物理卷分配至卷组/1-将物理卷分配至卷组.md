# 将物理卷分配至卷组

逻辑卷管理（LVM）提供了一种灵活管理磁盘空间的方法。使用 LVM 的第一步是初始化物理存储设备，即物理卷（PV），然后将它们组合成一个卷组（VG）。本挑战将重点关注这些初始步骤。

## 任务

- 将两个块设备初始化为 LVM 物理卷。
- 创建一个新的卷组，并将这两个新创建的物理卷添加到该卷组中。

## 要求

- 物理卷必须在 `/dev/vdb1` 和 `/dev/vdb2` 设备上创建。
- 新卷组的名称必须为 `vg_data`。
- 使用 `sudo` 执行需要根权限的命令。

## 示例

成功完成任务后，运行 `sudo pvs` 和 `sudo vgs` 命令应产生类似于以下的输出。具体的大小可能会略有不同。

```plaintext
$ sudo pvs
  PV         VG      Fmt  Attr PSize      PFree
  /dev/vdb1  vg_data lvm2 a--    1024.00m   1024.00m
  /dev/vdb2  vg_data lvm2 a--    1024.00m   1024.00m

$ sudo vgs
  VG      #PV #LV #SN Attr   VSize  VFree
  vg_data   2   0   0 wz--n-  1.99g  1.99g
```
