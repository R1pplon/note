# 删除逻辑卷

既然你已经学会了创建逻辑卷，下一步就是学习如何移除它们。当不再需要某些存储空间时，这是一项常见的管理任务。你将移除在上一步中创建的逻辑卷。

## 任务

- 从 `vg1` 卷组中删除逻辑卷 `lv1`。
- 从 `vg1` 卷组中删除逻辑卷 `lv2`。

## 要求

- 所有操作应在 `/home/labex` 目录或其子目录中进行。
- 使用 `lvremove` 命令删除逻辑卷。
- 待删除的逻辑卷名称必须符合任务要求。

## 示例

删除逻辑卷后，运行 `sudo lvs` 命令应该没有任何输出，或者至少不再显示 `lv1` 和 `lv2`。这表明逻辑卷已成功从 `vg1` 卷组中移除。
