# 通过 UUID 配置文件系统挂载

在这一步中，你将格式化一个新的存储设备，并配置系统使用其唯一标识符（UUID）进行自动挂载。这可以确保系统始终能够找到并挂载正确的设备，即使设备名称发生了变化。

## 任务

- 在本地存储设备上创建一个新的文件系统
- 配置系统在开机时通过 UUID 挂载该文件系统

## 要求

- 在 `/dev/vdb` 设备上创建一个新的文件系统
- 将该文件系统挂载到 `/mnt/data` 目录
- 配置系统在开机时通过 UUID 挂载该文件系统
- 验证文件系统是否已正确挂载

## 示例

成功完成上述步骤后，运行 `mount` 命令并过滤你的新挂载点，应该会产生类似以下的输出，确认 `/dev/vdb` 已正确挂载到 `/mnt/data`：

```bash
mount | grep /mnt/data
```

```
/dev/vdb on /mnt/data type ext4 (rw,relatime,seclabel)
```
