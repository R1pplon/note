# 创建自定义调优配置文件

你的首要任务是为自定义调优配置文件创建一个新目录并进行配置。该配置文件将继承 `balanced` 配置文件的设置，并添加一个关于最大打开文件数的自定义限制。

## 任务

- 为名为 `myprofile` 的新自定义调优配置文件创建一个目录。
- 创建一个包含 `balanced` 配置文件的配置文件 `tuned.conf`。
- 创建一个 `limits.conf` 文件来设置最大打开文件数。

## 要求

- 自定义调优配置文件目录必须创建在 `/etc/tuned/myprofile`。
- 配置文件 `/etc/tuned/myprofile/tuned.conf` 必须包含 `balanced` 配置文件。
- 必须创建一个新文件 `/etc/tuned/myprofile/limits.conf`。
- `limits.conf` 文件必须为所有用户设置 `nofile`（打开文件数）的软限制（soft limit）和硬限制（hard limit）均为 `4096`。
- 所有修改 `/etc` 目录下文件的操作必须使用 `sudo` 权限执行。

## 示例

创建自定义调优配置文件后，`/etc/tuned/myprofile/tuned.conf` 文件的内容应为：

```plaintext
[main]
include=balanced
```

`/etc/tuned/myprofile/limits.conf` 文件应包含：

```plaintext
* soft nofile 4096
* hard nofile 4096
```

## 提示

- 使用 `sudo mkdir -p` 命令来创建必要的目录结构。
- 使用像 `nano` 这样的文本编辑器来创建和编辑配置文件。例如：`sudo nano /etc/tuned/myprofile/tuned.conf`。
- 记住在 `/etc` 目录中创建或编辑文件时要使用 `sudo`，因为这些操作需要根用户（root）权限。
