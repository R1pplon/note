# 在仓库中创建 .github/workflows 目录

GitHub Actions 在你的仓库中一个特定的目录中查找工作流配置文件：`.github/workflows`。在这一步中，你将创建这个目录结构。

1. 确保你位于仓库目录下：

```bash
cd ~/project/github-actions-demo
```

2. 使用带 `-p` (parents) 标志的 `mkdir` 命令创建 `.github` 目录及其内部的 `workflows` 子目录：

```bash
mkdir -p .github/workflows
```

3. Git 不会跟踪空目录。为了确保我们可以在下一步中提交这个结构，让我们在这个目录下创建一个名为 `main.yml` 的简单空工作流文件。

```bash
touch .github/workflows/main.yml
```

4. 验证结构：

```bash
ls -R .github
```

**示例输出：**

```plaintext
.github:
workflows

.github/workflows:
main.yml
```

这个结构至关重要。GitHub 只会将放置在 `.github/workflows` 中的 YAML 文件识别为 Action 工作流。
