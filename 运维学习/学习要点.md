## 一、必须掌握的基础知识（高频出现）

### 1. 操作系统
- **Linux**（CentOS/Ubuntu/RedHat）：
  - 常用命令（`ls`, `grep`, `awk`, `sed`, `top`, `netstat`, `ps` 等）
  - 系统巡检、日志查看、服务管理（systemd）
  - 文件权限、进程管理、定时任务（cron）

### 2. 网络基础
- TCP/IP 协议栈、HTTP/HTTPS
- 常见网络故障排查工具：`ping`, `traceroute`, `telnet`, `netstat`, `curl`
- 抓包工具：`tcpdump`, Wireshark

### 3. 数据库基础
- **MySQL / PostgreSQL**：
  - 安装、配置、基本 SQL 语句（增删改查）
  - 日志查看、备份恢复
- Oracle
- PL/SQL

### 4. 脚本语言
- **Shell 脚本**：编写自动化任务、批量操作
- **Python**：基础语法、文件处理、调用系统命令、简单运维脚本
- **go**

## 五、学习建议（针对大三学生）

1. **打好基础**：Linux + 网络 + SQL + Shell/Python
2. **动手实践**：
   - 在虚拟机或云服务器上部署 LAMP / LNMP 环境
   - 搭建 Docker + Nginx + MySQL 服务
   - 使用 Prometheus + Grafana 监控本地服务
3. **做项目/实习**：哪怕是小项目（如自动化备份脚本、日志分析工具）也能加分
4. **准备面试**：常见运维面试题（如：CPU飙高怎么排查？如何做系统迁移？）
5. **考取证书（可选）**：RHCSA、CCNA、CKA（K8s）等
