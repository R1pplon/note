Ubuntu 24.04 LTS + Xray-core + VLESS + TLS（Cloudflare）+ Clash 客户端

## 安装 Xray

```bash
sudo apt update && sudo apt install -y curl unzip
curl -Ls https://github.com/XTLS/Xray-install/raw/main/install-release.sh -o install.sh
sudo bash install.sh
```

## Xray 配置（VLESS + WS + TLS）

配置文件在 `/usr/local/etc/xray/config.json`

可以通过 `systemctl cat xray` 查看

```bash
# 生成 UUID ,保存
cat /proc/sys/kernel/random/uuid
a3b2c5d1-xxxx-xxxx-xxxx-xxxxxxxxxxxx

nano /usr/local/etc/xray/config.json
```

```yaml
{
  "inbounds": [
    {
      "listen": "127.0.0.1",
      "port": 10000,
      "protocol": "vless",
      "settings": {
        "clients": [
          {
            "id": "你的UUID",
            "email": "clash"
          }
        ],
        "decryption": "none"
      },
      "streamSettings": {
        "network": "ws",
        "wsSettings": {
          "path": "/ray"
        }
      }
    }
  ],
  "outbounds": [
    {
      "protocol": "freedom"
    }
  ]
}
```

## 配置nginx

```bash
sudo apt install -y nginx

nano /etc/nginx/sites-available/default
```

```yaml
server {
    listen 443 ssl;
    server_name vpn.yourdomain.com;

    ssl_certificate /etc/ssl/cf.crt;
    ssl_certificate_key /etc/ssl/cf.key;

    location /ray {
        proxy_redirect off;
        proxy_pass http://127.0.0.1:10000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

## Cloudflare Origin 证书

Cloudflare：

SSL/TLS → Origin Server → Create Certificate

得到：

- origin cert
- private key

保存到服务器：

```bash
sudo mkdir -p /etc/sslsudo
nano /etc/ssl/cf.crtsudo
nano /etc/ssl/cf.key
```

## 启动服务

```bash
sudo systemctl restart nginx
sudo systemctl restart xray

sudo systemctl enable nginx
sudo systemctl enable xray
```

## 开放端口

- HTTP：80/TCP
- HTTPS：443/TCP

不需要开放10000

## clash 客户端

导入配置即可

```yaml
proxies:
  - name: MyVPS
    type: vless
    server: <域名>
    port: 443
    uuid: <你的UUID>

    network: ws
    tls: true
    udp: true

    servername: <域名>

    ws-opts:
      path: /ray
      headers:
        Host: <域名>

proxy-groups:
  - name: Proxy
    type: select
    proxies:
      - MyVPS

rules:
  - MATCH,Proxy
```
